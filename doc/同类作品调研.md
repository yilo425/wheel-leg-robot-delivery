## 2. ★ 台阶策略：我们做的和学术界一致

IEEE 有篇专门讲爬楼梯策略的：

> **Stair-Climbing Strategy in a Novel Wheel-Legged Hybrid Robot**
> "Upon entering the staircase, Kilin must prepare to **lift its front legs** to ascend the first stair"
> —— [IEEE 11533382](https://ieeexplore.ieee.org/document/11533382/figures)

**标准四步**（和我们 `main_fsm` 的 LIFT 模式 1 一模一样）：

```
① 抬前腿 → 车头上仰
② 前进 → 前轮压上台阶
③ 抬后腿（前腿保持）
④ 前进 → 后轮上台阶 → 收腿
```

✅ **这说明我们 RTL 里 `LP_F_UP → LP_F_CROSS → LP_R_UP → LP_R_CROSS` 的分段设计是对的**，
不是拍脑袋 —— 直接照抄了行业范式。

## 4. ★ 尺寸参考：别的赛事里台阶/障碍物有多大

一个"物资搬运"类赛事的场地规格（[原文 PDF](http://www.tastm.cn/static/upload/file/20231129/1701223422111230.pdf)）：

```
低层台阶：长60 × 宽30 × 【高 6cm】
高层台阶：长60 × 宽30 × 【高 12cm】
物资：      【5cm 立方体】泡沫模块
```

**这条对我们很有用**：

| 发现 | 对我们的意义 |
|---|---|
| 常见"低台阶"是 **6cm** | 我们的举升能力必须 ≥6cm（L=70mm 举升 119mm ✓ 富余很大）|
| 常见"高台阶"是 **12cm** | 12cm 必须**绕行**，别想跨 |
| 障碍物常是 **5cm 立方体** | 和你们说的"5cm 门槛"是同一量级 ✓ |

⚠️ **但要注意**：如果障碍物**本身就是 5cm 立方体**，
那"<5cm 抬腿 / >5cm 绕路"这个判据就**正好卡在边界上** ✗

**建议改成**：

```
≤ 4cm  → 不抬腿，直接压过去（4cm 以下轮子能过）
4~7cm  → 抬腿跨（0x04）
> 7cm   → 绕行（0x02）
```

留出**迟滞区间**，避免"5cm 的东西一会儿跨一会儿绕"。

## 5. 视觉判高度：单目可以，但要"地面假设"

学术/工程上的通用做法是**反投影 + 地面平面假设**（我们之前推导的公式就是它）：

```
已知相机高度 hc、俯仰角、焦距 f
地面上的点：row → 距离 D = hc / tan(θ(row))
物体顶边：  H = hc − D · tan(θ(row_top))
```

| 方案 | 依赖 | 可靠性 |
|---|---|---|
| 单目 + 地面假设 | 标定 hc / f / 俯仰 | ⭐⭐（近距离准，远了崩）|
| **单目 + TOF 距离** | 只标定 f | ⭐⭐⭐（我们讨论的那个方案）|
| **双 TOF 不同高度** | 装两个传感器 | ⭐⭐⭐⭐ **最稳，且不依赖颜色** |
| 双目/深度相机 | 硬件 | ⭐⭐⭐⭐ 但超预算 |

**参考**：障碍物边框 + 相机标定做平面信息提取，是已有专利做法
（[CN111179300A](https://patentimages.storage.googleapis.com/6f/25/4a/8e2672cf8bafce/CN111179300A.pdf)）。

### 9.1 ★ 成本答案：**只打印"零件"，不打印"框架"**

原作者的原文：

> **大部分零件使用 3D 打印制造，底板为定制亚克力板**
> 机器人底板使用的是**白色定制亚克力板**〔¥5〕
> 其余全部结构件均在嘉立创使用白色树脂材料打印，**全部花费约 ¥100**

**这直接回答了"3D 打印太贵"的问题**：

| 做法 | 成本 | 评价 |
|---|---|---|
| 整个车身 3D 打印 | ¥300~800 | ✗ 又贵又慢，大平面还容易翘 |
| **亚克力板（分层） + 铜柱 + 只打印支架** | **¥100~150** | ✅ **别人的实际做法** |

**分层靠什么**：`主控支撑铜柱` / `电池支撑铜柱` —— **M3 铜柱**，不是打印的框架 ✓
板子是**平板亚克力**（激光切割，¥5-15/块），打印件只做**立体的支架/卡扣** ✓✓

### 9.2 关节：**一个深沟球轴承 + 一个推力轴承**

| 件 | 规格 | 价 |
|---|---|---|
| 深沟球轴承 604 | 内4 / 外12 / 厚4 | ¥1.3 |
| **推力轴承 F8-14M** | 内8 / 外14 / 厚4 | ¥2.0 |

**"每个关节都用了一个深沟球轴承 + 一个推力轴承"** ——
这就是我们之前讨论的"舵机轴不能受弯矩"的正解：
- **深沟球轴承** 抗**径向**力（腿的侧向/上下载荷）
- **推力轴承** 抗**轴向**力（腿往外推的力）

> ✅ **这条直接验证了我给你的建议**：腿的另一端要加支撑。
> 对舵机来说，就是"腿根外侧装一个 604 轴承套在舵机盘外圈上"。

## 10. ★ 内部布局建议（照抄他的思路，适配我们的 4 轮 + 4 舵机）

### 10.1 先纠正你现在的分层

| 你的方案 | 问题 |
|---|---|
| 下层：4 舵机 + 电源 | ✅ 对（重的在下面）|
| 中层：FPGA | ✅ 对 |
| **顶层：ARM + 充电宝** | ❌ **充电宝是最重的单体（~200g），放最高层 = 重心最高** |

**充电宝在顶上会有什么后果**：
- 重心抬高 → 转弯侧倾大、越障时容易翻
- 我们算过"倾覆校核"，重心高度 <45mm 才安全

### 10.2 建议的三层布局

```
  ┌─────────────────────────────────┐
  │ ③ 顶板（亚克力 3mm）            │  ← K230 + 摄像头（轻，视野好）
  │    铜柱 M3×4 (25mm)             │
  ├─────────────────────────────────┤
  │ ② 中板（亚克力 3mm）            │  ← FPGA + 四路驱动板
  │    铜柱 M3×4 (25mm)             │
  ├─────────────────────────────────┤
  │ ① 底板（亚克力 3mm）            │  ← 电池 + 充电宝 + 4 舵机（最重的都在底层）
  └─────────────────────────────────┘
       ○ 轮                    轮 ○
```

| 层 | 放什么 | 理由 |
|---|---|---|
| **底** | 电池、**充电宝**、4 舵机 | 最重的贴地 → 重心低 ✓ |
| **中** | FPGA、四路驱动板、降压模块 | 中等重量、接线集中 |
| **顶** | K230、摄像头、大电容 | 轻；摄像头要高才有视野 |

> **注意**：摄像头在**顶板前沿**，才能"看到 50cm 处的 5cm 障碍"
> （我们算过：相机高 10cm、水平、50cm 处能看到）→ 顶板高度要 ~100mm ✓

### 10.3 结构怎么搭（省钱版）

| 件 | 材料 | 价 |
|---|---|---|
| 3 块层板 | **亚克力 3mm，激光切割** | ¥5~15/块 |
| 立柱 | **M3 铜柱**（25/30mm）| ¥0.5/根 × 12 |
| 舵机支架 | 3D 打印 | ¥5/个 × 4 |
| FPGA 支架 | 3D 打印 | ¥8 |
| 相机支架 | 3D 打印 | ¥5 |
| 电池卡扣 | 3D 打印（**必须做**，他说扎带不牢）| ¥8 |
| **合计** | | **¥100~150** |

**关键**：亚克力板**只开孔**（螺丝孔、过线孔），**不打印大平面** ✓
- 平板打印又慢又容易翘
- 激光切割亚克力又快又平又便宜

### 10.4 ★ 布线怎么不太头疼（你的另一个痛点）

| 做法 | 具体 |
|---|---|
| **每层板开过线孔** | φ8~10，**位置错开**（上层和下层不在一条直线上，线不打架）|
| **分侧走线** | 电源线走**右侧**、信号线走**左侧**，避免平行干扰 |
| **边缘集束** | 每层的线在板边汇成一束，用**螺旋缠绕管**（¥5/米）包起来 |
| **扎带固定点** | 板上开 φ3 孔，尼龙扎带穿孔绑线 |
| **接插件同侧** | 所有插头朝**同一个方向**（比如都朝车尾），维修时不用翻车 |
| **锁扣接插件** | 用 **JST-XH（带锁扣）** 而不是杜邦（会松）|
| **电源线加粗** | 电机/舵机 18~20AWG，信号 24AWG |

**照着做的好处**：拆装一次不用"重新理线"，坏一根能单独换 ✓

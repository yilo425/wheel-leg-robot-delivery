| # | 注意 |

## 四、K230 ↔ FPGA 串口（3 根，交叉接）

| K230 排针 | 方向 | FPGA 球号 | **FPGA 孔位** |
|---|---|---|---|
| **11**（UART2_TXD）| → | `F16` | **底排 5** |
| **13**（UART2_RXD）| ← | `C19` | **顶排 7** |
| **9 或 14**（GND）| ↔ | GND | **顶排 15** |

> ⚠️ **交叉接**：K230 的 TX 接 FPGA 的 F16（不是 C19）
> ⚠️ **GND 必接**：K230 用充电宝供电时尤其关键，否则串口不通

## 八、电源接线

```
3S 锂电池 12.6V
  │
  ├─→ 5A 保险丝 ─→ 驱动板 Vin+ ─→ 电机（4 路）
  │               驱动板 Vin− ─→ 电池负极
  │
  ├─→ LM2596 降压模块
  │     ├─ 输入+ ← 电池正极
  │     ├─ 输入− ← 电池负极
  │     └─ 输出+ = 9.2V ─→ FPGA DC 圆口
  │
  ├─→ UBEC 降压模块（12V → 5V）
  │     ├─ 输入+ ← 电池正极
  │     ├─ 输入− ← 电池负极
  │     └─ 输出+ = 5.16V ─→ PCA9685 的 V+（舵机电源）
  │
  └─→ FPGA 3.3V（底排 6）─→ PCA9685 的 VCC（逻辑电源）
```

### 共地清单（全部必须连在一起）

```
电池− / 驱动板 Vin− / UBEC 输入− / LM2596 输入− /
FPGA GND（顶排 6 或 15）/ PCA9685 GND / K230 GND
```

## 九、上电顺序

```
① FPGA 先上电（LM2596 输出 9.2V）
② 看 D0 亮、D3 亮（I²C / PCA9685 就绪）
③ UBEC 通电，等 1~2 分钟（它刚上电会先输出 ~11.8V，慢慢降到 5.16V）
④ 确认稳定后再给舵机供电（PCA9685 的 V+）
⑤ K230 上电（USB 或充电宝）
```

> ⚠️ UBEC 未稳定时给舵机供电会烧舵机 ✗

## 十、接线后自检（15 分钟，非常值得）

```
□ 1. 万用表蜂鸣档，逐根验排线（一端按 FPGA 孔，一端按驱动板脚）
□ 2. 任意两根信号线之间不导通（不短路）
□ 3. STBY（底排 9）接了没有
□ 4. 所有 GND 是否共地
□ 5. 手转每个电机，确认顺滑（不卡）
□ 6. 上电：D0 / D1 / D3 / D4 / D7 亮
□ 7. 舵机通电后往里收 30°（腿垂直）
```

## 十一、通道 → 车轮 映射

| 通道 | 车轮 | 驱动板座 |
|---|---|---|
| **A** | **左前** | `Motor_A` |
| **B** | **左后** | `Motor_B` |
| **C** | **右后** | `Motor_C` |
| **D** | **右前** | `Motor_D` |

**转向系数**（`STEER_COEF`）：A=+1、B=+1、C=−1、D=−1（左轮加速、右轮减速）

**方向取反**（`DIR_INV_MASK`）：`4'b0100`（只取反 C）

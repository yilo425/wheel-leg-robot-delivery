## 3. ★ 六个已经定下来的结论（别再重复讨论）

### ① 低矮障碍判据：5cm → **4 / 7cm 双阈值**

```
≤ 4cm   → 不抬腿，直接压过去
4~7cm   → 抬腿跨（发 0x04）
> 7cm    → 绕行（发 0x02）
```
**原因**：常见障碍物就是 **5cm 立方体**（查到的同类赛事场地规格），
判据卡在 5cm 会"一会儿跨一会儿绕"来回抖。

### ② 充电宝**不能放顶层**

最重的单体（~200g）放最高层 = 重心最高 → 转弯侧倾、越障易翻。
**挪到最底层**（和电池、舵机一起）。

### ③ 腿长 **70mm**，但**收起角不能用 45°**

`45° 收起时腿尖离地 = 舵机轴高 − 49.5mm` → 轴高不够就是**负的（扎地里）**。
- 要么舵机轴装到 ≥65mm 高
- 要么腿缩短到 50~55mm
- **这个数现在就能量**：拿打印件比一下

### ④ 舵机接法：用**原厂 25 齿舵机盘**，埋进腿根的 U 型槽

- **绝不自己打印花键**（25 齿精度打印不出来）
- 盘的一条臂埋进腿根槽里，**2 颗 M2 穿透**（用最内 + 最外两个孔，间距 14mm）
- 另一条臂**切掉**
- 力矩余量 10~30 倍 ✓

### ⑤ 层板用**亚克力 + 铜柱**，只打印支架 → 省 ¥200+

参考开源项目（1800⭐）的做法：**底板亚克力 ¥5，全部打印件 ¥100**。
- 层板：激光切割亚克力 3mm（¥5~15/块）
- 分层：**M3 铜柱**，不是打印框架
- 打印件只做支架/卡扣（舵机架、FPGA 架、相机架、电池夹）

### ⑥ 腿不能只靠舵机轴，**要加轴承**

开源项目在**每个关节**都放了：深沟球 604（抗径向）+ 推力轴承 F8-14M（抗轴向）。
舵机输出轴受弯矩会很快旷掉。

板子到货：**四路驱动板**。舵机控制板和电源模块**还没到**。

**所以今天只接：信号线 + 地线。**

```
① 所有电源不接，SW1 拨 OFF
② 先接地（FPGA GND ↔ 板 GND ↔ 舵机 −，三点连通）
③ 电机线（粗线，别插到编码器针上）
④ 逻辑 12 根 + STBY + 编码器 8 根
⑤ 舵机信号 2 根
⑥ 核对清单
⑦ 拍照存档
```

⚠️ **舵机的红线（+）今天必须完全悬空** —— 没有 5V 电源时，
接到 FPGA 的 5V 会拉垮 FPGA，接 12V 直接烧舵机。

**完整接线表见 `doc/四路板接线说明.md`**（含每根线的球号 + 物理孔位）。

## 9. 板上怎么判断状态（没接串口时看灯）

| 灯 | 含义 |
|---|---|
| D0 | 复位完成（常亮 = 板子活着）|
| D1 | 电机使能中 |
| D2 | 正在避障 / 越障 |
| D3 | 故障 |
| D4/D5/D6 | 状态机：2=AUTO `010`、3=AVOID `011`、4=LIFT `100`、6=ESTOP `110` |

> ⚠️ **D5 亮在 state=2 和 6 时都成立**（它只是 bit1）。
> 判断 AUTO 要看"**D5 亮 + D6 灭 + D4 灭**"。

## 1. 这是什么

轮足复合式机器人的 FPGA 主控：

```
感知          决策              执行
TOF ──┐                    ┌── 电机 ×4（PWM + 方向 + 编码器闭环 + 堵转保护）
IMU ──┼─► main_fsm ────────┼── 舵机 ×4（升降腿，50Hz 位置 PWM）
ARM ──┘   (状态机)          └── LED / 串口遥测
   ↑
视觉结果（UART 帧）
```

**核心设计原则**：每个等待都有超时；安全逻辑不依赖上层；输出单拍脉冲；
每个 `always` 都有复位分支；所有阈值参数化。

## 5. 接口约定（改之前先看）

### 5.1 引脚（`constraints/pin_table.csv` 是唯一真源）

| 功能 | FPGA 引脚 |
|---|---|
| 串口 TX / RX（**接 ARM**）| **`C19`** / **`F16`** ⚠️ 不是 M15/J21 |
| I2C SCL / SDA（TOF + IMU）| `M13` / `M16` |
| 电机 PWM `[0..3]` | `A13 A14 A15 A16`（左前/右前/左后/右后）|
| 电机方向 `[0..3]` | `A18 A19 F13 F14` |
| 电机使能 `m_en` | `E13`（**默认下拉 = 上电停车**）|
| 编码器 A/B `[0..3]` | `E14/C13` `B13/D14` `D15/C14` `C15/B15` |
| 舵机 `lift_pwm[0..1]` | `B16`（前腿组）/ `D17`（后腿组）|
| 限位 `lift_lim_n[0..1]` | `C17` / `B17`（低有效）|
| 终点限位 `goal_reached` | `E16`（**低有效**）|

### 5.2 串口协议（详见 `doc/uart_frame_protocol.md`）

```
0xAA 0x55 | VER=0x01 | TYPE | LEN(大端2B) | DATA | BCC | 0x55 0xAA
BCC = XOR(VER, TYPE, LEN_H, LEN_L, DATA...)
```

- `0x02 VISION_RESULT`：ARM → FPGA（类别 0x02 障碍物 / 0x04 低矮障碍 …）
- `0x10 TELEMETRY`：FPGA → ARM，10Hz，**13 字节**载荷

### 5.3 关键参数（`rtl/top.v` 的参数区，改这些就能调行为）

| 参数 | 默认 | 作用 |
|---|---|---|
| `TOF_ENABLE` / `IMU_ENABLE` | 1 / 1 | 器件没接时置 0，退回桩数据 |
| `VREF_FULL` | 69 | 满速对应的编码器计数（**要实车标定**）|
| `DIST_STOP_MM` / `DIST_SLOW_MM` | 200 / 500 | 避障阈值 |
| `GUARD_RAMP_STEP` | 8 | 软启动：每 1ms 最多加多少 duty |
| `GUARD_STALL_DUTY` / `STALL_MS` | 40 / 500 | 堵转判定（**要实车标定**）|
| `TELEM_RATE_HZ` | 10 | 遥测频率 |

## 6. 不要改的东西（铁律）

1. **`constraints/top.cst` 是生成物** —— 改 `pin_table.csv` 然后 `python tools/gen_cst.py`
   （手抄 140 行约束最危险的错误是"把 `m_pwm[2]` 抄成 `m_pwm[1]` 的球号"，
   Gowin **不报错**，结果是两个轮子一起动）
2. **`.v` 文件不能带 BOM**；`.ps1` **必须带** BOM；`.tcl`/`.sdc` **必须纯 ASCII**
   （Gowin 按 GBK 读，中文注释会烂成 `????`）
3. **Verilog-2001**：不能对 `parameter` 位选；不能在 `always` 里声明 `wire`
4. **每个 `always` 都要有复位分支**
5. **所有等待都要有超时**（串口、I2C、舵机动作都需要，否则丢一帧就永久卡死）
6. **安全逻辑不依赖上层**（急停要在最底层 0 拍生效）

## 8. 一组"改了就会坏"的仿真断言（别人踩过的）

| 断言 | 背后的问题 |
|---|---|
| `tb_motor_guard` 的逐拍斜坡检查 | `motor_guard` 的"下降"必须在 **tick 之外**当拍生效，否则减速晚 1ms（= 刹车延迟）|
| `tb_top_integration` 的 5.2 舵机脉宽 | 必须**量宽度**，不能"采一个瞬间"（50Hz 里高电平只占 5%）|
| `tb_top_integration` 的软启动等待 | 加了 `motor_guard` 后占空比是**爬升**的，启动后不能立刻测 |
| `tb_top_i2c_share` 的交叉污染检查 | 两个 I2C 从机必须"只对命中地址应答"，否则共享总线会互相应答 |
| I2C 仲裁器的释放条件 | 必须"既没请求也不忙"才释放；只看 `!busy` 会提前一拍释放 → 两个 master 撞车 |

## 1. 板子上的接口（照丝印对）

### 1.1 顶部

| 丝印 | 是什么 | 怎么用 |
|---|---|---|
| `Vin+` / `−`（**蓝色 2 位接线柱**）| 电机/逻辑**总电源输入** | 接电池（4.5~15V）|
| `SW1`（**三位拨动开关**，标 `ON` / `OFF`）| 板上电源开关 | 接线时拨到 **OFF** |
| `GND GND GND` / `3V3 3V3 3V3` / `5V 5V 5V` | 板上稳压器的**输出**排针 | **别接回 FPGA**（见 §5 红线）|

> ⚠️ `Vin` 有极性、**没有反接保护**。接线前先确认 `Vin+` 是对应电池正极。

### 1.2 左侧逻辑输入排（2×6，对应通道 A / B）

从上到下（丝印）：

```
3V3    STBY
PWMB   PWMA
BIN2   AIN2
BIN1   AIN1
E2A    E1A
E2B    E1B
```

### 1.3 右侧逻辑输入排（2×6，对应通道 C / D + 电流采样）

```
ADC    GND
PWMD   PWMC
DIN2   CIN2
DIN1   CIN1
E4A    E3A
E4B    E3B
```

> ★ `ADC` 很可能是**电流采样输出**（板上通常有个分流电阻）。
> 如果确认是，它正好能用来做"堵转检测"（比现在的"靠超时猜"强得多）。
> **本次先不接、不依赖，等用万用表确认再说。**

### 1.4 四个电机接口（白色插头，底部 + 左右）

| 接口 | 丝印引脚顺序（从照片读）|
|---|---|
| `Motor_A`（左）| `AO2` `3V3` `E1A` `E1B` `GND` `AO1` |
| `Motor_B`（底左）| `BO2` `3V3` `E2B` `E2A` `3V3` `BO1` |
| `Motor_C`（底右）| `CO1` `GND` `E3A` `E3B` `3V3` `CO2` |
| `Motor_D`（右）| `DO2` `3V3` `E4B` `E4A` `GND` `DO1` |

**含义**：
- `?O1` / `?O2` = 电机两根线（**接 MG310 最粗的红黑**）
- `3V3` = 编码器电源
- `?Ax` / `?Bx` = 编码器 A/B 相
- `GND` = 编码器地
- ⚠️ **B / C 两个口的 3V3 有 2 个、GND 是 3V3** —— 这块板四个口的针序**不完全一样**，
  接线时**按各自丝印**，别照搬 A 口的顺序 ✗

> 编码器信号在板上有**两处**：
> ① 电机接口里（给电机插头用）
> ② 逻辑输入排的 `E1A/E1B ... E4A/E4B`（**这才是接 FPGA 的**）
> 二选一即可，别两个都接。

## 4. 为什么舵机电源今天不能接

| 尝试 | 后果 |
|---|---|
| 舵机 `+` 接 FPGA 的 `5V`（底排 15）| ✗ 4 个 MG996R 要 2~4A，FPGA 的 5V 只有 ~0.5A → **FPGA 复位** |
| 舵机 `+` 接板的 `5V` 输出排 | ✗ 那是**逻辑用**的小稳压器（几十 mA），会烧 |
| 舵机 `+` 接 `Vin+`（12V）| ✗ **12V 直接烧舵机** |

**正确做法（等电源模块到了）**：
```
电池 → DC-DC 5V/5A → 舵机分配板 → 4×舵机
                     ↑
           并 1000µF 电容
```

## 5. 三条红线（通电前必须再确认一次）

1. **FPGA 的 3V3 / 5V 绝不接** 板的 `Vin`、舵机电源、电机电源。

## 6. 引脚分配的逻辑（为什么是这些球号）

### 6.1 第一层约束：**只有 GPIO0 扩展口能用**

| 位置 | 能不能接杜邦线 | 结论 |
|---|---|---|
| **GPIO0 2×20 排针** | ✅ 母座 + 每个孔旁边**印着球号** | **全部功能都放这里** |
| 板上 UART 焊盘（M15/J21）| ❌ 是焊盘不是排针 | 弃用（调试串口另接 USB-TTL）|
| 板载 I2C 排针 | ⚠️ 丝印有歧义，插错就烧 | 弃用（I2C 也挪到 GPIO0）|

**所以 49 个引脚全在 GPIO0 上** —— 这是唯一"能接线、能核对"的地方。

### 6.2 第二层：**按功能分块，块内相邻**

```
底排 20 ~ 顶排 17   →  电机 PWM / 方向      （12 根，连成一条扁带）
顶排 16 ~ 底排 11   →  编码器 4 组 A/B      （每组两根相邻）
顶排 11 / 底排 10   →  舵机 2 路
顶排 10 / 底排 8    →  限位 2 路
顶排 7 / 底排 5     →  串口 TX/RX
```

好处：**每一束线走一条边**，不会在板子中间交叉 ✓

### 6.3 第三层：**下标约定全项目统一**

```
0 = 左前  1 = 右前  2 = 左后  3 = 右后
```

**为什么重要**：这个顺序必须和 `motion_decision.v` 的 `STEER_COEF = +1,+1,-1,-1`
一致。曾经 RTL 按"左右"分组、引脚表按"位置"编号 → **转向整个反过来** ✗

### 6.4 第四层：**上拉/下拉按信号类型配**

| 信号类型 | 配置 | 为什么 |
|---|---|---|
| 编码器 A/B | `PULL_MODE=UP` | 霍尔是**开漏**，必须上拉；不接时读稳定高（不计数）|
| 限位开关 | `UP` | 常开到 GND，未按=1、按下=0 |
| 超声波 ECHO | **`DOWN`** | 模块没接时读 0（=没有回波），不会乱飘 |
| 舵机 PWM / 电机 | `NONE` | 推挽输出，不需要上下拉 |
| 串口 RX | `UP` | 空闲高电平（UART 的 idle 状态）|
| **`m_en`（STBY）** | **`DOWN`** | **上电默认停车**（安全默认值）|

> `STBY` 配 `DOWN` 是有意的：FPGA 没配置好之前，板上驱动是关闭的 ✓

### 6.5 第五层：**留余量**

| 剩余资源 | 用途 |
|---|---|
| `E17`（顶排 5）| **唯一空闲的 GPIO0 脚** —— 留给将来的电流采样 / 第 5 路信号 |
| 板上拨码开关 SW0~7（8 个输入）| 可做模式选择，不占 GPIO0 |
| 板上 LED4~8 | 已用于 `state_dbg` / `speed_scale_dbg` |

### 6.6 一个已知未确认项

`N19` 同时被标为 **LED8** 和**无源蜂鸣器 BEEP** —— 下次上板用万用表量一下，
如果真冲突，`speed_scale_dbg[1]` 要换脚（文档里备选写的是 B17，
但 B17 现在被 `lift_lim_n[1]` 占了，**需要重新选**）。

## 7. 接线顺序（今天按这个来）

```
① 所有电源不接（Vin、舵机+、电池）
② SW1 拨到 OFF
③ 先接【地】：FPGA GND ↔ 板 GND ↔ 舵机 −（3 个点连通）
④ 再接【电机线】：4 组 AO1/AO2 ...（粗线，注意别插到编码器针上）
⑤ 再接【逻辑】：12 根（§2.2）+ STBY + 编码器 8 根（§2.3）
⑥ 最后接【舵机信号】：2 根（B16 / D17）
⑦ 按 §3 清单逐条核对
⑧ 拍照留档（以后拆了能对着接回去）
```

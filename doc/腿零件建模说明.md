# 腿零件建模说明（2026-10-22）

> 模型文件：`mech/leg_70mm.scad`（参数化 OpenSCAD）
> 预览图：`mech/leg_70mm_preview.png`（不用装软件就能看）
> 生成脚本：`tools/gen_leg_model.py`（改参数后重跑，图和 scad 一起更新）

---

## 1. 为什么给 OpenSCAD 而不是直接给 STL

**STL 是"死"的**。下面两个尺寸我**不知道**，你们一量就会发现和我的默认值不一样：

| 尺寸 | 我猜的默认值 | 实际要量 |
|---|---|---|
| 舵机盘（六芒星）外接圆半径 | **10 mm**（φ20）| 卡尺量"尖到圆心" |
| 舵机盘内接圆半径 | **6.5 mm** | 量"凹处到圆心" |
| MG310 的 4 个 M3 方阵边长 | **16 mm** | 量对角孔距 ÷ 1.414 |

**给了 STL 就得重画；给了 OpenSCAD，改 3 个数字重按 F6 就行** ✓

## 2. 怎么用（3 步）

```
① 装 OpenSCAD（免费 20MB）：https://openscad.org/downloads.html
② 打开 mech/leg_70mm.scad，改最上面【必改：实测参数】那三个数
③ 按 F6（渲染）→ File → Export → Export as STL
```

**打印参数**：

| 项 | 值 |
|---|---|
| 材料 | **PETG** |
| 填充 | **60~80%** |
| 壁厚 | **4 圈** |
| 摆放 | **平躺**（厚度 8mm 朝 Z，长度沿 XY）|
| 支撑 | 不需要（无悬空）|

> ⭐ **平躺打印**是关键：层线沿腿长方向，抗弯最强。
> 立着打会从分层面劈开。

## 3. 模型的关键尺寸

```
        舵机轴中心                     电机轴中心
             ↓                              ↓
    ┌────────────────────────────────────────┐
    │   ⬢ 六芒星凹槽              ○    ○     │  ↑ 8mm 厚
    │   ⊕ 中心 M3 孔              ○    ○     │  ↓
    └────────────────────────────────────────┘
    ←──────────── L = 70 mm ────────────────→
     ← 根部 φ27 →
```

| 参数 | 值 | 说明 |
|---|---|---|
| **腿长 L** | **70 mm** | 舵机轴 → 电机轴（你定的 7cm）|
| **厚度** | **8 mm** | 沿舵机轴方向（你定的 8mm）|
| 根部圆 | **φ27 mm** | 容下 φ20 六芒星 + **3.5mm 壁厚** |
| 中段宽度 | **16 mm**（x=45 处）| 收腰，减重 |
| 尖端宽度 | **21 mm** | 加宽给电机座 |
| 六芒星凹槽 | 深 **2.6 mm**，过盈 **0.15 mm** | 压入后有"齿感" |
| 中心孔 | **φ3.5** 贯穿 | M3 从最外面穿进去 |
| 电机 4 孔 | **M3，方阵 16mm** | ★ 必须量 |
| 电机凸台让位 | **φ12** 贯穿 | ★ 必须量 |
| **体积** | **13.7 cm³** | |
| **单条重量** | **17.4 g**（实心）/ **≈13 g**（60% 填充）|
| **4 条合计** | **≈52 g**（60% 填充）|

> **重量很轻** —— 因为我们之前算过腿根应力只有 0.35 MPa（PETG 45 MPa），
> 余量 26 倍，所以腿可以做得很省料 ✓

## 4. 装配（3 步，只靠一颗 M3）

```
        M3 螺丝（从最外面拧）
          ↓
      φ8 钢垫片   ← ★ 必须有！否则螺丝头压进 PETG
    ┌──────────┐
    │  腿（凹槽）│   ← 六芒星压进这个槽
    ├──────────┤
    │ 舵机盘(⬢) │   ← 嵌在槽里，6 个面传扭矩
    ├──────────┤
    │  25齿花键  │
    └──────────┘
         舵机
```

**装配**：
1. 六芒星**压进**腿的凹槽（手掌压 / 台钳轻压；太紧用烙铁烫一下）
2. 整体套到舵机花键上（对准齿）
3. 从外面拧 **M3 + φ8 垫片** → 一次压紧"腿 + 盘"

**扭矩三重保险**：

| 途径 | 余量 |
|---|---|
| 六芒星 6 面形状配合 | 形状驱动（只要不剪断齿）|
| M3 压紧的摩擦 | ≈1.2 N·m vs 需要 0.075 → **16 倍** |
| 垫片防蠕变 | 长期不松 |

**防松**：M3 上滴**中强度螺纹胶**（乐泰 243）✓

## 5. ★ 你们需要量的 5 个数（卡尺，10 分钟）

| # | 量什么 | 怎么量 | 填进 scad 的哪个参数 |
|---|---|---|---|
| 1 | 舵机盘**尖到圆心** | 卡尺从中心孔到星尖 | `STAR_RO` |
| 2 | 舵机盘**凹处到圆心** | 卡尺从中心孔到凹处 | `STAR_RI` |
| 3 | 舵机盘**厚度** | 卡尺 | `STAR_DEP` = 该值 + 0.1 |
| 4 | MG310 **对角孔距** | 卡尺量两个对角 M3 孔中心 | `MOT_BOLT_SQ` = 对角 ÷ 1.414 |
| 5 | MG310 **凸台直径** | 卡尺 | `MOT_BOSS_D` |

> 量完把数发我，我帮你填进去 + 重新出图核对 ✓

## 6. 装好后必须做的 3 个测试

| # | 测试 | 判据 |
|---|---|---|
| 1 | **手掰**（抓腿末端绕舵机轴扭）| 扳不动、**看不到旷动** ✓ |
| 2 | **手压**（腿末端往下压）| 不晃、螺丝不松 ✓ |
| 3 | **拆装 3 次** | 每次都能压紧、不滑丝 ✓ |

**第 1 条最关键** —— 能扭动哪怕 1°，装车后走直线就会偏 ✗

## 7. 已知风险 / 后备方案

| 风险 | 现象 | 对策 |
|---|---|---|
| 六芒星孔旷 | 腿有旷量、走不直 | ① 加大过盈到 0.25 ② 压入后**滴 502 固定**（不打算拆的话）|
| 压不进 | 装不上 | 用**烙铁烫一圈**再压（PETG 软化温度 ~80°C）|
| M3 松 | 越跑越旷 | 螺纹胶 / 弹簧垫圈 |
| 电机孔距量错 | 装不上 | ★ **先量再打印**，别先打后量 |

### 4.2 GPIO0 —— **建议分配，请按此接线**

> ★ **轮子编号（按位置，全项目统一）**：
> ```
> 0 = 左前 FL -> 左轮   1 = 右前 FR -> 右轮
> 2 = 左后 RL -> 左轮   3 = 右后 RR -> 右轮
> ```
> `STEER_COEF` = `+1, -1, +1, -1`（左 +1 / 右 −1）。
> **必须和 `rtl/app/motion_decision.v` 保持一致** —— 不一致会让转向整个反过来。
>
> 这是**接线约定**，不是板上固定接线。谁先定谁省事。
> 下标约定：**0=左前 1=右前 2=左后 3=右后**。
> ⚠️ 装反了车会原地打转。接好线后**先架空轮子验证转向**。

| 信号 | 引脚 | GPIO0 | 说明 |
|---|---|---|---|
| `m_pwm[0..3]` | `A13` `A14` `A15` `A16` | _0~3 | 四路 PWM |
| `m_dir[0..3]` | `A18` `A19` `F13` `F14` | _4~7 | 四路方向 |
| `m_en` | `E13` | _8 | 驱动使能（**默认下拉=上电停车**）|
| `enc_a[0]` / `enc_b[0]` | `E14` / `C13` | _9 / _10 | 左前 |
| `enc_a[1]` / `enc_b[1]` | `B13` / `D14` | _11 / _12 | 右前 |
| `enc_a[2]` / `enc_b[2]` | `D15` / `C14` | _13 / _14 | 左后 |
| `enc_a[3]` / `enc_b[3]` | `C15` / `B15` | _15 / _16 | 右后 |
| `lift_pwm[0]` / `lift_pwm[1]` | `B16` / `D17` | _17 / _18 | 输出：前腿组 / 后腿组舵机 PWM |
| `lift_lim_n[0]` / `lift_lim_n[1]` | `C17` / `B17` | _19 / _22 | 输入：前/后腿抬起到位（**低有效**）|
| `lift_fault_n[0]` / `lift_fault_n[1]` | `B18` / `C18` | _23 / _24 | 输入：前/后腿舵机故障（**低有效**，不接=1=正常）|
| `goal_reached` | `E16` | _20 | 输入：终点限位（**低有效**，接地=到达；未接=上拉=未到达）|
| `error_flag` | `D16` | _21 | 输出：故障指示 |
| **`uart_tx`** | **`C19`** | **_25** | 输出：→ ARM 的 **RX**（2026-10-17 新增）|
| **`uart_rx`** | **`F16`** | **_26** | 输入：← ARM 的 **TX**（2026-10-17 新增）|
| **`sr04_trig`** | **`F20`** | **_35** | 输出：HC-SR04 触发（`TOF_IF=1` 时用）|
| **`sr04_echo`** | **`E18`** | **_34** | 输入：HC-SR04 回波（**必须 ≤3.3V！**）|

> ★ **接 ARM 的接法（交叉！）**：
> ```
> ARM 排针 11 (UART2_TXD) ──► FPGA 的 F16 孔
> ARM 排针 13 (UART2_RXD) ◄── FPGA 的 C19 孔
> ARM GND ──────────────────── FPGA 的 GND 孔（扩展口上就印着 GND）
> ```
> 两块板都是 3.3V，直连。**GND 那根不能省**。

> ★ **接 HC-SR04 超声波（`TOF_IF=1`）**：
> ```
> 模块 Vcc  ──  3V3（底排第 6）      ⚠️ 先按 3.3V 供电，别上 5V
> 模块 Gnd  ──  GND（顶排第 6）
> 模块 Trig ──  F20（顶排第 1）
> 模块 Echo ──  E18（顶排第 2）
> ```
> ⚠️ **ECHO 是输入，模块按 5V 供电时它会输出 5V —— 会打死 3.3V 的 IO。**
> 宁可欠压不工作（3.3V 供电），也不能过压。要 5V 供电必须在 ECHO 上串
> 1k+2k 分压（5V→3.33V）。
>
> 原理：拉高 TRIG 10µs → 模块发 8 个 40kHz 波 → ECHO 高电平宽度 = 往返时间。
> 声速取 343m/s，`距离(mm) = ticks×450 >> 17`（50MHz 下，误差 <0.15%）。

## 5. 为什么把两个接口从顶层去掉了

原来 `top.v` 需要 **119 位引脚**，而板子可用 IO 只有 **约 53 个** —— 超出 66 位，**物理上放不下**。

| 去掉的 | 位数 | 理由 |
|---|---|---|
| `uart_rx_ok_cnt` 等 4 个统计端口 | **64** | **纯仿真用**。板上看不到；联调信息走 TELEMETRY 从串口发出。改成 `top.v` 内部 wire，`tb_top_integration` 用层次引用读 |
| `dist_mm[15:0]` + `dist_valid` + `dist_err` | **18** | **16 位并行 TOF 现实中不存在**。真实模块走 I2C/UART（2 根线）。**已落地**：`tof_driver` 走 I2C（`M13`/`M16`），距离在片内组织成 `dist_mm`；`DIST_STUB_MM` 参数只在 `TOF_ENABLE=0` 的联调模式下生效 |

**去掉后 40 位，加上 TOF 的 2 根 I2C = 42 位，稳稳放下，还留 11 个 GPIO0 备用。**

> 这不是"砍功能"，是设计修正：统计端口只在仿真里有意义；TOF 该由一个内部驱动模块解析后输出 `dist_mm`，而不是从 16 根线进来。

## 6. 怎么改引脚

**不要直接编辑 `constraints/top.cst`** —— 它是生成的，会被覆盖。

```powershell
# 1) 改 constraints/pin_table.csv（只填 pin 那一列）
# 2) 重新生成
python tools/gen_cst.py
```

脚本会检查：漏填、**重复球号**、引脚名格式（防止把封装脚位序号当成球号）、电气属性取值。

> 手抄 140 行约束最危险的错误不是漏写，而是**把 `m_pwm[2]` 抄成 `m_pwm[1]` 的球号**
> —— Gowin **不会报错**，结果是两个轮子一起动。

## 8. ★ 器件型号的最终确认（2026-10-13，实测）

**型号走过两次弯路，最终靠芯片自己报的 ID 定案。**

| 阶段 | 判断 | 依据 | 结果 |
|---|---|---|---|
| 1 | `GW5A-25A` | 口头信息 | ❌ 错 |
| 2 | `GW5AST-138` | 原理图 `GW5AT-138K-PG484A` + 引脚表球号范围（22×22 需 PBGA484A） | ❌ 仍错（漏看有无 "S"）|
| 3 | **`GW5AT-138`** | **芯片实测 ID = `0x0011081B`** | ✅ **对** |

### 怎么定的案

`programmer_cli` 连上后读出芯片 ID，再从 `jtagserver.exe` 里挖出高云自己的 ID 表：

```
u0001481B  GW5AT_60_ID
u0011081B  GW5AT_138_ID      ← 实测读到的就是这个
u0001081B  GW5AST_138_ID     ← 138 带 S 的是这个（差一位）
u0001281B  GW5A_25_ID
```

### 实测数据

```
1 device(s) found!
ID Code is:     0x0011081B
User Code is:   0x00009480
Status Code is: 0x00026020
```

### ⚠️ 由此引出的硬约束：需要支持 GW5AT-138 的 Gowin 版本

**Gowin EDA V1.9.11.03 Education 不支持 GW5AT-138**（实测）。

它的 `IDE\data\device\device_package.csv` 里 GW5AT 系列只有：

```
gw5ast138b-011  GW5AST-138B  PBGA484A
gw5ast138c-007  GW5AST-138C  PBGA484A
gw5at60b-007    GW5AT-60B    UBGA225
gw5at60b-002    GW5AT-60B    PBGA484A
```

`programmer_cli --device` 的合法取值也只有 14 个，**没有 GW5AT-138**：

```
GW1N-1P5C GW5AST-138B GW5AST-138C GW5AT-60B GW5AS-25B GW1NZ-1
GW1NSR-4C GW1N-9C GW1NR-9C GW2A-18C GW2AR-18C GW5A-25A GW5A-25B GW5ART-15A
```

**症状**：能通信、能读 ID，但 `--run 2/3` 报 `ID code mismatch`，而且**根本没法为它综合**（器件目录里没有）。

**解决**：装 **Gowin EDA V1.9.12 或更新**；建议用 **Standard 版**（免费 license，器件支持最全，教育版器件是精简的）。装的时候**路径必须纯 ASCII**。

> **最省事的办法**：直接问小梅哥 / 看课程资料用的是哪个版本。

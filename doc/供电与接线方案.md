## 1. 电源选型（为什么是这些）

### 1.1 电池：**3S 12V，不能用 2S 7.4V**

| 负载 | 需要电压 | 2S 7.4V 行不行 |
|---|---|---|
| **FPGA** | **DC 9~12V** | ❌ **7.4V 低于下限**，要加升压 |
| 电机（TB6612）| 4.5~15V | ✅ |
| 舵机（经 UBEC）| 6V | ✅（UBEC 降压）|
| K230 | 5V | 用充电宝，无关 |

**结论**：FPGA 决定了必须上 **9V 以上** → **3S 12V** ✓

| 项 | 规格 | 价 |
|---|---|---|
| **电池** | **3S 18650 动力电池组 11.1V 3000mAh，带保护板** | ¥50~80 |
| 备选 | 3S LiPo 2200mAh 25C（XT60）| ¥60~100 |
| 充电器 | 12.6V 2A（18650 组）/ 3S 平衡充（LiPo）| ¥20~30 |

**放电能力够不够**：

```
典型负载：电机 1.2A + 舵机 1.1A + FPGA 0.25A ≈ 2.5A @12V
峰值（堵转）：电机 4A + 舵机 4A ≈ 8A
→ 3000mAh 动力电池 10A 放电 ✓ 够，续航约 1 小时
```

### 1.2 三个降压模块

| 用途 | 规格 | 关键点 | 价 |
|---|---|---|---|
| **FPGA** | 12V → **9V / 2A** | ⚠️ **不能直连 12V**：满电 12.6V 超规格 | ¥8~15 |
| **舵机** | 12V → **6V / 5A**（推荐 **UBEC**）| 必须独立，不能从 FPGA 取 | ¥20~35 |
| **K230** | —— 用**充电宝 5V/2A** | 最省事，还隔离噪声 | ¥50~80 |

**为什么舵机用 UBEC 而不是 LM2596**：

| | UBEC（航模）| LM2596 模块 |
|---|---|---|
| 电流 | **真 5A** | 标 5A，实际 3A |
| 滤波 | 好（专为舵机/接收机设计）| 一般，纹波大 |
| 可靠性 | 高 | 一般 |

**选 6V 档**（MG996R 在 6V 下扭矩 13 kg·cm，比 5V 的 9.4 大 40%）。

### 1.3 电机为什么能直连 12V

MG310 额定 7.4V，吃 12V 会过压 60%。

**用固件限压**（已实现）：`V_LIMIT_DUTY = 68` → 占空比 53% → 等效 6.4V ✓

> 升级选项：加一个 **12V→7.4V/5A** 降压（¥15），电机就吃干净直流，
> 固件里把 `V_LIMIT_DUTY` 改回 128。**现在不用，先白嫖软件限压。**

## 2. 配电：怎么把 12V 分成三路

**核心：一个"12V 汇流节点"**（2 位接线端子排），什么线都能拧上去。

| 件 | 规格 | 价 | 作用 |
|---|---|---|---|
| XT60 母头带线 | 14AWG | ¥3 | 电池接口 |
| **2 位接线端子排** | 5.08mm，能过 10A | ¥1.5 | **12V 汇流** |
| **片式保险丝座 + 5A 片** | 汽车用 | ¥3 | ★ 防短路（必装）|
| 船型开关 | 10A | ¥2 | 总电源开关 |
| 硅胶线 | 18AWG 红黑（电机）+ 20AWG（舵机）| ¥10 | |

### 接法

```
电池 XT60 公
   │
   ├─ 红线 → 保险丝 → 开关 → 端子排【红排】
   └─ 黑线 ─────────────→ 端子排【黑排】
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
   四路板 Vin+ 拧         UBEC 红线 拧          DC-DC 红线 拧
   四路板 Vin− 拧         UBEC 黑线 拧          DC-DC 黑线 拧
   （18AWG 粗）           （20AWG）              （20AWG）
```

**一根端子排能拧几根？** 5.08mm 端子每个孔能拧 2~3 根 20AWG ✓
三路刚好 ✓（如果嫌挤，买 3 位的）

## 3. 各模块接线（完整表）

### 3.1 电源类

| 模块 | 从哪取电 | 接口 |
|---|---|---|
| TB6612 四路板 | 12V 汇流 | `Vin+/−` **螺丝端子/焊盘**（粗线）|
| UBEC 输入 | 12V 汇流 | 裸线拧端子 |
| DC-DC 12V→9V 输入 | 12V 汇流 | 裸线拧端子 |
| **FPGA** | DC-DC 的 9V 输出 | **DC5.5×2.1 免焊转接端子** ¥2 → 板上 DC 圆口 |
| **舵机 ×4** | UBEC 的 6V 输出 | 舵机**分配板**的螺丝端子 |
| **K230** | **充电宝** | Type-C |

### 3.2 信号类（全部以 FPGA 为中心）

| 模块 | 根数 | FPGA 引脚 | 孔位 |
|---|---|---|---|
| **K230 串口** | 3 | `uart_tx`=`C19` / `uart_rx`=`F16` / GND | 顶排7 / 底排5 |
| **四路板逻辑** | 14 | 12 信号 + `STBY` + GND | 见 §3.3 |
| **编码器** | 8 | `enc_a/b[0..3]` | 见 §3.4 |
| **HC-SR04** | 4 | VCC→3V3 / GND / `sr04_trig`=`F20` / `sr04_echo`=`E18` | 底排6 / 顶排6 / 顶排1 / 顶排2 |
| **限位 ×2** | 6 | VCC→3V3 / GND / OUT=`C17`,`B17` | 见 §3.5 |
| **舵机信号** | 2（→4）| `lift_pwm[0]`=`B16` / `lift_pwm[1]`=`D17` | 顶排11 / 底排10 |

### 3.3 四路板（14 根）

| 通道 | PWM | 方向1 | 方向2 |
|---|---|---|---|
| A 左前 | `A13` 底排20 → `PWMA` | `A18` 底排18 → `AIN1` | `F19` 底排1 → `AIN2` |
| B 右前 | `A14` 顶排20 → `PWMB` | `A19` 顶排18 → `BIN1` | `F18` 底排2 → `BIN2` |
| C 左后 | `A15` 底排19 → `PWMC` | `F13` 底排17 → `CIN1` | `E19` 底排3 → `CIN2` |
| D 右后 | `A16` 顶排19 → `PWMD` | `F14` 顶排17 → `DIN1` | `D20` 底排4 → `DIN2` |
| 使能 | `E13` 底排16 → `STBY` | | |
| 地 | FPGA GND → 板 `GND`（逻辑排上那个）| | |

**方向上不接的三根（今天不接）**：板上的 `3V3`（左排顶，**绝不接**）、`ADC`（待验证）、GND（要接）。

### 3.4 编码器（8 根，板的逻辑排 → FPGA）

| 轮 | 板上 | FPGA | 孔位 |
|---|---|---|---|
| 左前 | `E1A` | `enc_a[0]`=`E14` | 顶排16 |
| | `E1B` | `enc_b[0]`=`C13` | 底排14 |
| 右前 | `E2A` | `enc_a[1]`=`B13` | 顶排14 |
| | `E2B` | `enc_b[1]`=`D14` | 底排13 |
| 左后 | `E3A` | `enc_a[2]`=`D15` | 顶排13 |
| | `E3B` | `enc_b[2]`=`C14` | 底排12 |
| 右后 | `E4A` | `enc_a[3]`=`C15` | 顶排12 |
| | `E4B` | `enc_b[3]`=`B15` | 底排11 |

**规律**：A 相全在**顶排**（16/14/13/12），B 相全在**底排**（14/13/12/11）。

### 3.5 限位开关（2 个 3 针模块）

| 模块引脚 | 接 | 孔位 | 备注 |
|---|---|---|---|
| **VCC** | **`3V3`** ⚠️ | **UART 那边的 3V3**（已确认标着 3V3）| **绝不能接 5V** |
| GND | 任一 GND | 顶排15 | |
| OUT（前腿）| `lift_lim_n[0]`=`C17` | 顶排10 | 内部上拉，**触发=0** |
| OUT（后腿）| `lift_lim_n[1]`=`B17` | 底排8 | 同上 |

**为什么 VCC 用 UART 那边的 3V3**：GPIO0 只有**一个** 3V3（底排6），
留给超声波；限位模块用第二个 3V3 取电点 → **不用分线** ✓

**★ 接之前必须量极性**（万用表直流档，OUT 对 GND）：

| 读数 | 判断 |
|---|---|
| 不触发 3.3V、触发 0V | ✅ 直接接 |
| 不触发 0V、触发 3.3V | ❌ 极性反，换模块的 NO/NC 焊盘 |
| 不触发 5V | ❌ VCC 接错 |

**限位开关是必需的**：`lift_done` 只来自开关，没有"超时当到位"的兜底 →
不装就每次抬腿都超时 → 降级绕行 → **越障永远不成功**。

### 3.6 舵机（4 个 / 2 路信号）

| 舵机线 | 颜色 | 接 |
|---|---|---|
| 信号 | 黄/橙 | 分配板的信号针（经 Y 线从 FPGA 来）|
| 电源 + | **红** | **分配板的 + 排**（6V）|
| 地 | 棕/黑 | **分配板的 − 排** |

## 4. ★ 共地拓扑（星形接地，做错会各种怪毛病）

```
     电池负极 ────┬────────────┬─────────────┬───────────────┐
     （粗线）      │            │             │               │
              四路板 Vin−   UBEC 输入 −   DC-DC 输入 −    （主参考点）
                  │            │             │
             4 个电机地    4 个舵机地       FPGA 板地
                          （经分配板）
                                                       ▲
                                                  一根【细线】
                                                       │
                                                  FPGA GND
```

### 规则

| 什么 | 接到哪 |
|---|---|
| **功率地**（电机、舵机）| **电源负极**（粗线）|
| **信号地**（限位、超声波、编码器、串口）| **FPGA 的 GND** |
| 两者之间 | **一根细线**（单点参考）|

### 为什么不能全接 FPGA GND

```
舵机 4A × 地线电阻 0.05Ω = 0.2V 地压差
  → 逻辑"高电平"被抬高 0.2V
  → 串口乱码 / 编码器乱跳 / FPGA 偶尔复位 ✗
```

**这就是"舵机一动 FPGA 就重启"的根因**。

> **今天是演示（不通电）**：所有地并到 FPGA GND 上没问题 ✓
> **正式通电前必须把功率地拆出来**，改回星形。

## 5. ★ Y 线用在哪，为什么

**一共要 2 根 Y 线**，用途是**分信号**（不是分电源）：

```
FPGA `B16`（顶排11，单孔）──Y线(公转双母)──┬── 分配板 输出1 的信号针
                                            └── 分配板 输出2 的信号针
                                                  → 前腿 2 个舵机同步

FPGA `D17`（底排10）──────Y线──────────────┬── 输出3 信号针
                                            └── 输出4 信号针
                                                  → 后腿 2 个舵机同步
```

**为什么必须用 Y 线**：GPIO0 是**单孔母座**，插不进两根线 ✗
分配板的信号针是**公针**，也塞不进两个母头 ✗
→ **Y 线（一个公头插 FPGA + 两个母头套公针）正好解决** ✓ ¥3/根

**电源不用 Y 线**：分配板的螺丝端子直接拧 UBEC 的线 ✓

## 7. 接线顺序（照这个来，能救命）

```
【第一次装配，全程断电】
① 焊/拧好 12V 汇流：XT60 母头 → 保险丝 → 开关 → 端子排
② 万用表通断档：电池正极 ↔ 负极 **不能导通**（确认没短路）
③ 接三路负载的电源线（四路板 / UBEC / DC-DC）
④ 接信号线：串口 → 超声波 → 限位 → 编码器 → 电机逻辑 → 舵机信号
⑤ 接舵机电源（UBEC → 分配板 → 4 个舵机）
⑥ **先不接舵机**，上电测三路电压：12V / 6V / 9V 都对
⑦ 断电，接舵机，再上电
⑧ 按 `doc/明日上板检查单.md` 逐项验
```

### ★ 上电前必查 5 条

| # | 查什么 | 判据 |
|---|---|---|
| 1 | 电池正负极 **不短路** | 通断档不响 |
| 2 | 四路板 `Vin` 极性 | 红线在 `Vin+` |
| 3 | 限位模块 VCC 接的是 **3V3** 不是 5V | 目视 |
| 4 | 舵机红线接的是 **分配板**，不是 FPGA | 目视 |
| 5 | 舵机/电机的**功率地**没接到 FPGA GND | 目视（星形接地）|

## 8. 三条红线（违反就烧东西）

1. **FPGA 的 3V3 / 5V 绝不接** 四路板 `Vin`、舵机电源、电机电源。
2. **四路板的 `3V3` / `5V` / `ADC` 排针绝不接回** FPGA（两个稳压器并联会倒灌）。
3. **`Vin` 反接 = 报废**（这块板无保护）。

# 一、FPGA 代码对硬件的硬性要求

## 1.1 电机

| 要求 | 值 | 来自哪里 |
|---|---|---|
| 类型 | **有刷直流 + 减速箱** | 驱动板用 PWM+DIR，无刷需要 FOC |
| 额定电压 | **12V** | 和电池/驱动板匹配 |
| **必须带编码器** | 见 §1.2 | `encoder_decode.v` 需要 4 路 AB 相 |

**转速要求（软性，可以标定）**

代码里的满速参考值：

```verilog
// rtl/top.v
parameter integer SPEED_WIN = 500_000;   // 测速窗口 = 10ms @50MHz
parameter integer VREF_FULL = 60;        // 满速目标计数/窗口
```

换算公式（**4 倍频**，来自 `encoder_decode.v`）：

```
每轮一圈的计数 = PPR × 4 × 减速比

VREF_FULL = (目标RPM / 60) × (PPR × 4 × 减速比) × 0.01
```

**结论：减速比在 1:10 ~ 1:200 之间都能适配** —— 我改一个参数就行。
**不需要**因为"减速比不合适"而挑型号。

## 1.2 ★★ 编码器（**最容易买错，也是唯一会烧板子的一项**）

### 必须满足

| # | 要求 | 说明 |
|---|---|---|
| **1** | **增量式正交编码器（AB 两相）** | `encoder_decode.v` 用 **4 倍频正交解码**<br>❌ 只有单相脉冲输出的**不行**（测不出方向）|
| **2** | **编码器供电能接 3.3V** | ★★★ **最重要**，见下面 |
| **3** | **输出电平 ≤ 3.3V** | FPGA IO 是 `LVCMOS33` |
| **4** | 推挽或开漏输出都可以 | IO 端已配上拉（`PULL_MODE=UP`） |

### ⚠️⚠️ 为什么"3.3V 供电"是生死线

引脚表里编码器是这样配的：

```
enc_a[0],E14,LVCMOS33,UP,,GPIO0_9     ← IO 类型 3.3V，上拉
```

**FPGA 的 IO 绝对最大输入电压是 3.6V 左右**（LVCMOS33 的 VIN max）。

**市面常见的霍尔编码器：**
- 供电 **5V** → 输出 **5V** 方波
- **直接接进 FPGA → IO 长期过压 → 打死 IO（不可恢复）**

**这比"接错线"更危险** —— 因为一开始可能"能用"，IO 在慢慢损坏，几天后才失效，**根本查不出来**。

### 三种解法（按推荐度）

| 方案 | 做法 | 评价 |
|---|---|---|
| **① 编码器用 3.3V 供电** | 大部分霍尔编码器 **3.3~5V 都支持** | ★★★ **首选**，问商家确认 |
| **② 加电平转换** | TXS0108E / 74LVC245（8 路，¥5） | 编码器必须 5V 时用 |
| ③ 分压电阻 | 两个电阻分压 | ❌ 边沿变慢，高速丢计数 |

**代码侧的证据**：`encoder_decode.v` 有 `FILTER_CYCLES=8` 数字滤波
（8 × 20ns = **160ns** → 理论最高约 3MHz），
**我们不靠硬件分压来降速，而是靠 3.3V 供电避免过压。**

## 1.3 电机驱动板

| 要求 | 值 | 来自 `pwm_motor.v` |
|---|---|---|
| **控制接口** | **PWM + DIR** 两根线 | `pwm_out` + `dir_out` |
| **逻辑电平** | **3.3V 兼容** | FPGA 输出 LVCMOS33 |
| 通道数 | 4（2 片 TB6612） | `m_pwm[3:0]` / `m_dir[3:0]` |
| 使能 | 有 STBY/EN 脚（高有效） | `m_en` |
| 电流 | ≥1A/通道 | 12V 减速电机堵转约 1-2A |

**TB6612FNG 完全匹配** ✓（VCC 2.7-5.5V，PWM+DIR+STBY）

**❌ 不兼容的**：
- **L298N** —— 逻辑电平 5V，**3.3V 驱动不可靠** ⚠️
- **只有单线"正反转"接口**的驱动板
- **串口/I2C 控制的驱动板**（如某些"智能驱动器"）

---

## 1.4 舵机

| 要求 | 值 | 来自 `servo_lift.v` |
|---|---|---|
| 类型 | **180° 位置舵机** | ❌ **不要 360° 连续旋转型** |
| 控制信号 | **标准 50Hz PWM**（0.5~2.5ms） | 周期 20ms，`PWM_MIN_US=500` / `PWM_MAX_US=2500` |
| 扭矩 | ≥13 kg·cm | 见 `采购清单.md` §2.2 验算 |
| 齿轮 | 金属 | 承重 |
| **供电** | **独立 5V/≥5A** | ⚠️ 不能从 FPGA 板取电 |

**⚠️ 首次调试提醒**：不同舵机行程不一样。
如果舵机在 0.5/2.5ms 时"顶到机械限位发出嗡嗡声"，把
`servo_lift.v` 里的 `PWM_MIN_US` / `PWM_MAX_US` 改小
（比如改成 1000 / 2000）再试。

---

## 1.5 限位开关

| 要求 | 值 |
|---|---|
| 类型 | **常开（NO）微动/行程开关** |
| 接法 | 一端接 **GND**，另一端接 FPGA 输入 |
| 代码侧配置 | **上拉**（`PULL_MODE=UP`）→ 未按下读 1，按下读 0 |

**⚠️ 代码里有个已知 bug**（还没修，上板前会修）：
`main_fsm` 里写的是 `if (lift_done)`（高有效），但上拉后"未按下=1"，
会**一进 LIFT 就误判到位**。已在 `servo_lift.v` 里做极性转换解决。

**⚠️ 如果不装限位开关**：`lift_done` 永远不成立 → 每次抬腿 3 秒后超时 → 急停。
**所以限位开关是必须的**，或者我改代码支持"无反馈模式"（你说一声即可）。

## 1.6 TOF / IMU

| 要求 | 值 |
|---|---|
| 接口 | **I2C**（`SDA=M16`、`SCL=M13`） |
| 电平 | **3.3V** |
| 型号 | VL53L0X（TOF）/ MPU6050（IMU） |

**⚠️ 多个 I2C 器件地址冲突**：VL53L0X 默认地址相同，
两个 TOF 需要**改地址**（XSHUT 逐个上电改）或**加 I2C 多路复用器**（TCA9548A，¥5）。

# 三、到货验收方法

**收到货后，**按顺序做，**不要直接往 FPGA 上插**。

## 步骤 1：先量编码器输出电平（★ 最关键）

```
1. 给编码器接上它标称的供电电压（先别接 FPGA）
2. 用万用表/示波器量 A 相输出的高电平
   - 手动慢慢转动电机轴，观察 A 相电压跳变
3. 如果高电平 > 3.5V：
   → 不要接 FPGA！
   → 先确认编码器能不能改 3.3V 供电
   → 不能的话买电平转换模块
```

**这一步能救你一块开发板。**

## 步骤 2：确认 AB 两相正交

```
1. 示波器（或逻辑分析仪）同时看 A 相和 B 相
2. 缓慢转动电机轴
3. 正常现象：两路方波，频率相同，相位差 90°
4. 异常：只有一路在动 → 单相编码器，不兼容
         两路完全同相 → 接线或编码器有问题
```

**没有示波器的话**：接到 FPGA 后用 `pos_cnt` 观察 ——
正转 `pos_cnt` 增加、反转减少，就说明方向能识别 ✓

## 步骤 3：确认电机转向

```
1. 电机不接编码器，直接接驱动板
2. 给一个小的 PWM + DIR=1
3. 观察电机实际转向，记录方向
4. 四个电机装到车上后，确认"左轮正转 = 车前进"
```

## 步骤 4：确认驱动板逻辑电平

```
1. 驱动板 VCC 接 3.3V（不是 5V）
2. 用 FPGA（或 3.3V 电源 + 电阻）给 PWM 脚一个方波
3. 电机能动 → 3.3V 兼容 ✓
4. 电机不动 → 逻辑电平不兼容，要换驱动板
```

## 步骤 5：记录标定参数

**把这四个数发给我，我改 `VREF_FULL`：**

| 参数 | 值 |
|---|---|
| 减速比 | |
| PPR | |
| 编码器供电电压 | |
| 编码器输出高电平 | |

# 四、不兼容红线（**买了就废**）

| ❌ 红线 | 为什么 |
|---|---|
| **无刷电机**（BLDC / 轮毂电机） | 需要 FOC 或六步换相，FPGA 侧没有 |
| **步进电机** | 需要细分驱动器 |
| **只有单相脉冲的编码器** | 测不出方向，`encoder_decode` 用不了 |
| **绝对式/串行编码器**（如 AS5600 I2C） | 需要专门驱动，现在没有 |
| **编码器只能 5V 供电且不能加转换** | 会打死 FPGA 的 3.3V IO |
| **L298N 驱动板** | 逻辑电平 5V，3.3V 驱动不可靠 |
| **串口/I2C 控制的"智能驱动板"** | 接口完全不匹配 |
| **360° 连续旋转舵机** | 代码发的是位置 PWM，会一直转 |

---

# 五、总结：一句话版

> **电机**：有刷 + 减速 + **AB 相正交编码器**
> **编码器**：★★★ **必须能 3.3V 供电**（或加电平转换）
> **驱动板**：**PWM + DIR**，**3.3V 逻辑兼容**（TB6612 ✓，L298N ✗）
> **舵机**：**180° 位置型**，金属齿，独立 5V/5A 供电
>
> **减速比和 PPR 随便，我改个参数就能适配 —— 但上面四条不能错。**

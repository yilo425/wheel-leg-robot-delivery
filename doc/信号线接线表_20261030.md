# 十、新方案（2026-10-31）：两条 2×5 排线，跨层只走一根扁平线

> 动机：FPGA 在二层、驱动板在一层，22 根散线跨层太乱。
> 关键发现：**FPGA 排针顶排全是奇数 GPIO0、底排全是偶数，同一位置上下差 1**
> —— 正好匹配 2×N 排线的 1/2 脚顺序。

## 10.1 为什么最多一条 10 根

```
顶/底排 位置 16~20  ->  GPIO0_9 ~ GPIO0_0   连续 10 个 ✓
顶/底排 位置 15     ->  GND / 5V            ← 断点 ✗
顶/底排 位置 10~14  ->  GPIO0_19 ~ GPIO0_10 连续 10 个 ✓
位置 9 及左侧       ->  GPIO0_20 起，被 LED/按键/UART/I2C 占用
```

**所以一条排线最多 10 根**，两条共 20 根，覆盖 4 PWM + 8 方向 + 8 编码器 ✓

## 10.5 效果

```
改前：14 根电机散线 + 8 根编码器 = 22 根散线跨层 ✗
改后：2 条 2×5 扁平排线（各 10 根）+ STBY + GND = 4 根跨层 ✓
```

## 10.7 ⚠️ 改线后的验证

2. 确认 A、B 两路转向一致、编码器反馈正常
3. 再插排线 B（C/D 两路）
4. 最后测左右转 90°

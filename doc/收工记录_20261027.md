## 2. 抓到并修掉的两个 ARM 侧真 Bug

### ① `uart.any()` 谎报（"0 帧"的真凶）

```
u.any()  → 1        ← 假的
u.read() → 1320 B   ← 实际有这么多
```

旧 `_read_available()` 按 `any()` 的数量读 → **每 10ms 只读 1 字节**（≈100 B/s），
而 FPGA 以 220 B/s 发 → 缓冲溢出丢字节 → 帧永远拼不完整。

> 现象就是那句 `收到 0 帧；噪声 299B`，而 299 ≈ 3 秒 × 100 B/s，完全吻合。

**已改**：不再问 `any()`，直接 `uart.read()`（`timeout=0` 仍非阻塞）。

### ② 遥测第 0 字节拆错

格式是 `{1'b0, flags[3:0], state[2:0]}`，旧代码把整字节当 state → 打出 `UNKNOWN(64)`。
**已改**：`state = b0 & 7`、`flags = (b0 >> 3) & 0xF`（文档里的 `>>2` 也一并修正）。

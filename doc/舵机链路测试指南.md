# 舵机链路测试指南（FPGA → PCA9685 → 舵机）

> 2026-10-29 晚实测通过：4 只 MG996R 全部同时抬起 ✓
> 本文记录**接线 + 测试步骤 + 排障表**，下次换舵机/换车体照着做即可。

---

## 1. 链路

```
FPGA ──I2C(2根)──► PCA9685 控制板 ──PWM(16路)──► MG996R ×4
          + 3.3V/GND          + 舵机电源 6V（绿色端子）
```

| 层 | 谁负责 |
|---|---|
| 状态机 | `main_fsm` 输出 `lift_cmd[1:0]`（11=前后都抬）|
| I²C 主机 | `i2c_master`（`rtl/driver/i2c_master.v`）|
| 舵机驱动 | `pca9685_drv`（`rtl/driver/pca9685_drv.v`）|
| 固件开关 | `top.v` 的 **`SERVO_IF = 1`**（⚠️ 需同时 `TOF_IF=1`、`IMU_ENABLE=0`，I²C 只有一条）|

---

## 2. 接线（6 根 + 舵机）

| PCA9685 | FPGA | 孔位 | 注意 |
|---|---|---|---|
| `VCC` | **3V3** | **底排 6** | ⚠️ **绝不能接 5V**（I²C 电平会变 5V，打死 IO）|
| `GND` | GND | 顶排 6 | |
| `SCL` | `C20` | 顶排 4 | |
| `SDA` | `D19` | 顶排 3 | |
| `OE` | **GND** | 顶排 6 | 低有效，接高=输出关闭（舵机永远不动）|

### 舵机电源（绿色端子或从通道针进电）

```
UBEC / LM2596 输出 6V ──► POWER +（或任意通道的 U+ 针）
电源地              ──► POWER −（或任意通道的 GND 针）
                    └─ 再并一根细线 ──► FPGA 的 GND  ★ 共地必须
```

> **应急技巧**：没有一字螺丝刀时，可以从**任意通道的 `U+`/`GND` 针**用杜邦线进电
> （PCA9685 的 16 路 V+ 是同一根铜轨）。
> **但必须先量**：通道 0 的 `U+` ←→ 通道 4 的 `U+` **导通** ✓，且 `U+` ←→ `GND` **不通** ✓。

### 舵机插哪几路（固件写死）

| 通道 | 腿 |
|---|---|
| **0、1** | 前腿（2 只并联）|
| **2、3** | 后腿（2 只并联）|

**插头方向**：橙/黄→`PWM`、红→`U+`（中间）、棕/黑→`GND`（最下）⚠️ 插反烧舵机

## 3. 测试步骤

```
① 上电（FPGA 电池供电）→ 看 D3 亮（=PCA9685 初始化成功）★
② 按板上【S0】→ 进 AUTO → D1+D5 亮
③ 发一帧"低矮障碍"(0x04) → 触发 LIFT
④ 4 只舵机同时抬起 → 保持 lift_timeout → 放下
```

### 发帧（K230 侧，REPL 里跑）

```python
import sys; sys.path.insert(0, '/tmp')
import wifi_rc, uart_proto as up
import board_bringup as bb

u = wifi_rc._setup_uart()

# 可选：把抬腿保持时间改成 10 秒（默认 3 秒，太快看不清）
u.write(up.make_config(0x11, bytes([0x27, 0x10])))   # 0x2710 = 10000ms

# 发"低矮障碍"帧 → 抬腿（MANUAL_VECTORS[1] 就是它）
u.write(bb.MANUAL_VECTORS[1][1])
```

> ⚠️ 前置条件：FPGA 必须在 **AUTO**（按过 S0），在 IDLE 或 S_MANUAL 都会忽略视觉帧。

## 4. 排障表（每次都是这几条）

| 现象 | 原因 | 怎么查 |
|---|---|---|
| **D3 灭** | I²C 没通 | SCL/SDA 接反（**对调 C20/D19**）；`VCC` 不是 3.3V；`OE` 没接低 |
| **D3 亮但舵机不动** | 舵机/插头 | 插头方向；舵机是否烧（5V 充电器单独试）|
| **只有一路不动** | 那只舵机或那路通道 | 换一只舵机 / 换一个通道验证 |
| **舵机抖但不转** | 信号没到或方向反 | 核对插头三根线的位置 |
| **4 只都只动一点** | `lift_height` 太小 | 发 CONFIG `0x10`（0..100），默认 50 |
| **动作时电压掉到 4.5V 以下** | 电源线太细 / 接触不良 | 杜邦换硅胶线，或走绿色端子 |
| **舵机发烫/嗡嗡不停** | 堵转 | 立刻断电，检查机械是否卡住 |

---

## 5. 关键参数（CONFIG 帧可改，不用重新综合）

| ID | 参数 | 默认 | 范围 |
|---|---|---|---|
| `0x10` | 抬腿高度 | 50 | 0..100（100 = 2.5ms 全抬）|
| `0x11` | 抬腿动作超时 | 3000ms | 500..30000 |

## 6. 实测记录（2026-10-29）

| 项 | 结果 |
|---|---|
| 舵机电源 | UBEC 输出 **5.16V**（跳线在 5V 档；带载 4 只不动摇）|
| PCA9685 初始化 | **D3 亮** ✓ |
| 4 只同时抬腿 | **全部动作** ✓ |
| 抬腿保持 | 改成 10 秒后清晰可见 ✓ |
| 已知问题 | UBEC 曾出现一次 **11.8V** 读数，敲击跳线帽后不再复现 → 判为表笔误碰，但**该 UBEC 仍需持续观察** |

# 故障记录：驱动板 C 通道烧毁（已定案）

> 2026-10-30 晚，组装后首次四轮联调时发生。**根因已确认：带电接线时地线碰到 C 端子，打火短路。**

---

## 一句话结论

```
12V 已经接在端子上（带电状态），
把地线往端子里送的时候，地线碰到了 C 通道的端子，
"啪"的一声打火 —— 那是 0Ω 短路，
C 路 H 桥的高边 MOS 在几毫秒内被 10~30A 电流击穿。
```

**这不是板子质量问题，是接线事故** ✓（但没装保险丝是根本漏洞）

---

## 现象（事后测得的三个铁证）

| 项 | 表现 |
|---|---|
| **C 通道电机（左前）** | **完全不转**（其余 A/B/D 三路正常） |
| **驱动板 C 通道区域** | **异常发烫** |
| **CO1 对 GND** | **6V** |
| **CO2 对 GND** | **0V** |

正常工作时 CO1 与 CO2 应**互补输出 PWM**，两者平均值**之和 ≈ 电池电压**。
故障时 6V + 0V = 6V，差额 6V 全部消耗在芯片内部 → 发热、带不动电机。

---

## 为什么会这样（机理）

```
C 输出被直接短到地（0Ω）
        ↓
H 桥高边 MOS 承受全部电池电压，电流只受电池内阻和线阻限制
        ↓
瞬间 10~30A，芯片额定只有 1.2A（峰值 3.2A）
        ↓
MOS 管芯在几毫秒内过热击穿
        ↓
"啪"（电弧声）+ 事后 CO1 卡在 6V + 芯片持续发烫
```

**TB6612 只有欠压锁定和过温关断（150°C 结温）** ✗
**没有过流保护** ✗ —— 过温关断需要时间，几毫秒的短路根本来不及触发。
**任何同级芯片在这种情况下都会死** ✓ 不是这颗芯片特别差。

**只有 C 一路坏** ✓ 和"只有 C 端子被打到"完全吻合 ✓

---

## 排查过程（逐步排除，全部靠换线 + 万用表，没拆电机插头）

| 步骤 | 操作 | 结果 | 排除项 |
|---|---|---|---|
| 1 | 逐通道测试（`MOTOR_TEST_MODE` 逐路 1.5s + LED4/5 显示通道号）| C 通道灯亮但电机不转 | 确认是 C 这一路 |
| 2 | C 的 PWM 线与 D 互换（`A15` ←→ `A16`）| C 电机仍不转；D 电机照常转 | ✗ `A15` 引脚没问题 |
| 3 | C 的两根方向线也与 D 互换（`F13/E19` ←→ `F14/D20`）| C 电机仍不转 | ✗ `F13`/`E19` 也没问题 |
| 4 | 量 CO1 / CO2 电压 | CO1=6V、CO2=0V | ✗ 通道输出异常 |
| 5 | 量 4 个电机绕组电阻 | 4 个完全一致 | ✗ 电机没问题 |
| 6 | 回忆接线过程 | **带电接线时地线碰到 C 端子，有打火** | ★ **找到根因** |

**结论**：FPGA 侧全部正常，电机正常，问题是 C 路 H 桥被短路打穿 ✓

## 处理

1. **更换驱动板**（TB6612 四路裸板，¥20 左右；不必买 ¥60 带壳的）
2. **电池正极串 5A 车用保险丝** ★ 这次事件里它会在打火瞬间熔断，保住板子
3. **接线完全照旧** —— 引脚映射不用改（见 `doc/信号线接线表_20261030.md`）
4. **固件不用动**
5. 换板后先跑逐通道测试确认四路都正常，再关掉 `MOTOR_TEST_MODE` 烧正常固件

## 附：如何快速判断某一路是否烧了

```
① 万用表 DCV 20V，黑笔接驱动板 GND
② 红笔分别点该通道两个输出（X O1 / X O2）
③ 发测试让该通道输出
④ 正常：两者互补，各自平均值之和 ≈ 电池电压（如 5V + 7V）
   烧毁：一个卡在中间电平（如 6V）、另一个 0V；或两个都 0V / 都 12V
⑤ 摸芯片：发烫 = 内部漏电，基本确诊
```

# 十一、★ 2026-11-01 重大补充：更可能的根因是【电机堵转】

> 用户实测发现：**腿的电机安装孔用错 → 电机被压歪 → 输出轴抱死 → 轮子根本转不动**。
> 这为"驱动板烧毁"提供了一个比"接线短路"更完整、更常见的解释。

## 11.1 机械上的直接证据

```
腿模型 leg_70mm.scad 的电机安装孔是 12mm × 12mm 的【四孔方阵】：

     ●─────●          ← 相邻孔距 12mm（太窄，NG）
     │     │
     ●─────●          ← 对角孔距 12 × 1.414 = 17mm（✓ 正确）

用户实际用【相邻】两个孔上螺丝：
   → 孔距 12mm，比电机的 17mm 窄 5mm
   → 硬拧两颗螺丝 → 电机壳体被压歪/变形
   → 输出轴被轴承抱死 → 轮子转不动
```

**实测确认**：
- 只上 1 颗螺丝 → **轮子能转** ✓
- 上 2 颗相邻孔螺丝 → **完全锁死** ✗

## 11.2 由此推出的烧板链条（比短路更可信）

```
电机轴抱死（轮子转不动）
        ↓
用户发"前进"指令 → H 桥通电 → 电机堵转
        ↓
堵转电流 = 正常运行电流的 5~10 倍
（本机 MG310 实测绕组 60Ω，12V 堵转 ≈ 2~3A）
        ↓
TB6612FNG 额定 1.2A / 峰值 3.2A，**没有过流保护**
（只有欠压锁定 + 过温关断，结温 150°C 需要时间）
        ↓
H 桥 MOS 持续过热 → 击穿 ✗
        ↓
表现：单通道输出卡在中间电平（CO1=6V）+ 芯片发烫
```

**和实测现象 100% 吻合** ✓
**"啪"的打火声，可能是 MOS 击穿瞬间，也可能是插拔接线时的电弧** —— 两者都可能 ✓

## 11.3 结论修正

| 之前的判断 | 修正后 |
|---|---|
| ~~地线碰 C 端子短路是根因~~ | ⚠️ **可能只是诱因之一** |
| — | ★ **更可能的根因：电机安装孔用错 → 堵转 → 大电流烧 H 桥** |
| 板子质量问题 | ✗ 排除 |
| 电机质量问题 | ✗ 排除（电机好的，实测能转）|

**两条都要防**：既不能带电接线，也绝不能对抱死的电机通电。

## 11.4 ★★ 由此确立的三条铁律

| # | 铁律 | 原因 |
|---|---|---|
| **1** | **装完电机，先断电手转一遍，确认顺滑再通电** | 抱死的电机一通电就是堵转 |
| **2** | **轮子转不动时，绝对不要发运动指令** | 堵转 2~3 秒就足以烧 H 桥 |
| **3** | **电机安装用【对角】两个孔（17mm），不是相邻（12mm）** | 相邻孔会压歪电机、抱死轴 |

## 11.5 ✅ 后续确认：模型没问题（2026-11-01）

用户再次实测：**沉槽（CBORE_DEP/CBORE_D）起作用后，两颗螺丝拧死也完全顺滑、非常稳固** ✓

```
真正的锁死原因 = 螺丝头没沉进沉槽，露出部分顶到/压歪了电机壳体
                       ↓
                拧紧 = 加压 → 轴抱死
                       ↓
                通电 = 堵转 = 烧 H 桥
```

**所以模型不用改** ✓ 但要**确保螺丝头沉进沉槽**，别露头 ✓

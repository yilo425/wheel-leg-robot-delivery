## 0. 开箱先做三件事（不接线）

```
① 拍一张 4 路板的【正面 + 背面丝印】照片 → 确认引脚名（AIN1/AIN2/PWMA…）
```

## 1. FPGA 侧引脚（固定不变，照这张表接线）

| 信号 | FPGA 球号 | 孔位 | 说明 |
|---|---|---|---|
| `m_en` | `E13` | 底排 16 | 驱动板 `STBY`（**见 §2 的警告**）|
| `m_pwm[0]` | `A13` | 底排 20 | 电机 A 的 PWM |
| `m_dir[0]` | `A18` | 底排 18 | 电机 A 的方向 |
| `m_pwm[1]` | `A14` | 顶排 20 | 电机 B 的 PWM |
| `m_dir[1]` | `A19` | 顶排 18 | 电机 B 的方向 |
| `m_pwm[2]` | `A15` | 底排 19 | 电机 C 的 PWM |
| `m_dir[2]` | `F13` | 底排 17 | 电机 C 的方向 |
| `m_pwm[3]` | `A16` | 顶排 19 | 电机 D 的 PWM |
| `m_dir[3]` | `F14` | 顶排 17 | 电机 D 的方向 |
| `enc_a[0..3]` | `E14 B13 D15 C15` | — | 编码器 A 相 |
| `enc_b[0..3]` | `C13 D14 C14 B15` | — | 编码器 B 相 |
| **`m_dir2[0..3]`** | **`F19 F18 E19 D20`** | **底排 1/2/3/4** | **第二方向脚（接 AIN2/BIN2/CIN2/DIN2）** |
| GND | — | 顶排 6 / 15 | **必须共地** |

> 轮子编号约定：`0=左前 1=右前 2=左后 3=右后`

### ★ `m_dir2` 是什么（2026-10-18 新增，决定能不能倒车）

TB6612 **每个通道要两个互补方向脚**：

| AIN1 (`m_dir`) | AIN2 (`m_dir2`) | 结果 |
|---|---|---|
| 1 | 0 | **正转** |
| 0 | 1 | **反转** |
| 0 | 0 | 滑行（**倒不了车**，原地不动）|
| 1 | 1 | 刹车 |

`m_dir2[i] = ~m_dir[i]`，所以：

- **接上这 4 根** → 完整正反转 ✓（推荐）
- **不接、AIN2 照旧接地** → 只能前进，行为与以前一致（安全，但**倒不了车**）

> ⚠️ 不接这 4 根时，`AIN2/BIN2` **必须**接 GND —— **不能悬空**
> （悬空可能读成高 → AIN1=AIN2 → 刹车，电机不转还不发热，极难查）。

## 2. ⚠️ 三条硬规则（今晚用血换的）

### 规则一：`STBY` **先悬空**

很多驱动板的 `STBY` **内部上拉到它自己的 3V3**。从 FPGA 给它送高电平 =
把 FPGA 的 3.3V 和板子的 3.3V **并联倒灌** → 大电流 → **板子烫手**（今晚就发生了）。

```
先不接 STBY，只接 Vin/GND -> 看电源灯亮不亮
接通电机、给 PWM -> 电机能转，说明它自带使能，STBY 永远不用接
电机不转 -> 再接 STBY 到 FPGA 的 E13
```

### 规则二：**先验电源，再验信号，最后验负载**

```
① 电源：只接 Vin + GND -> 板载电源灯亮？       ← 不是 GPIO 探针！
② 信号：MOTOR_TEST_MODE=1 的固件 -> 电机有没有脉冲？
③ 负载：把电机直接接 FPGA 的 5V（红->5V, 黑->GND）-> 电机转不转？
```

**第 ③ 步最关键**：它把"FPGA → 驱动板 → 电机"三段压成一段，
一次就能判定"是电机坏还是驱动板坏"。今晚就是靠这一步定案的。

### 规则三：**占空比从低往上、堵转保护开着**

| 参数 | 台架起步值 | 说明 |
|---|---|---|
| `V_LIMIT_DUTY` | **68** | 12V 电池 → 电机 ≤7.4V（53%）|
| `GUARD_ENABLE` | **1** | 堵转保护必须开（今晚为让它转关掉了，等于拆保险）|
| 起步占空比 | **20~30** | 先看它能不能动，再往上加 |

> ⚠️ 没接编码器时 `spd_fb` 恒为 0，堵转保护会在 500ms 后误判并切断电机
> → 表现为"转半秒就停"。**这是保护在尽责，不是故障。**
> 台架上要么接受它断续转，要么先把编码器接好 —— **不要关掉保护**。

## 3. 上板步骤（按顺序，每步都有判据）

### 第 1 步：只接电源

```
接：电池+ -> Vin+    电池- -> Vin-
    （可选）FPGA GND -> 板子 GND（共地，后面接信号时必须有）
```

| 判据 | 结果 |
|---|---|
| 板载电源灯**亮** | ✅ 进入第 2 步 |
| 不亮 | ❌ 查：电池有没有电 / 开关有没有开 / 插头插到底 / 螺丝是否夹到线皮 |

### 第 2 步：烧自测固件，看电机脉冲

```
烧：robot_motortest.fs（MOTOR_TEST_MODE=1，已预编译好）
接：m_pwm[0..3] / m_dir[0..3]（4 路都接，或者先只接 A 路）
    STBY 先悬空
```

固件行为：**每 2 秒给 1.3 秒的 40% 占空比**，四个轮子同步。

| 判据 | 结论 |
|---|---|
| 电机每 2 秒转一下 | ✅ **链路通了** → 进入第 3 步 |
| 不转，但板载电源灯亮 | 接 `STBY` → `E13` 再试 |
| 还不转 | ❌ 做第 ③ 步（电机直连 5V）分离故障 |

### 第 3 步：换成正式固件，跑状态机

```
烧：robot.fs（MOTOR_TEST_MODE=0）
参数：TOF_ENABLE=0（桩数据 2000mm，全速）
      GUARD_ENABLE=0（台架，因为没编码器）
      V_LIMIT_DUTY=68
接：全部信号 + STBY（如果第 2 步需要的话）
操作：按 S0 -> AUTO（D5 亮、D6 灭）-> 电机持续转
```

| 判据 | 结论 |
|---|---|
| 电机持续转 | ✅ 状态机链路通 |
| 转一下就停 | 堵转保护（`GUARD_ENABLE` 看看是不是 1）|
| 完全不转 | 回第 2 步 |

### 第 4 步：接编码器（可选，进阶）

```
接：驱动板 E1A/E1B -> enc_a[0]/enc_b[0]，E2A/E2B -> enc_a[1]/enc_b[1]
    （编码器电源由驱动板的电机接口提供）
参数：GUARD_ENABLE=1（有反馈才能判堵转）
看：telemetry 里的速度是不是非 0（需要 ARM）
```

**没接 ARM 时**：只能靠"堵转保护不再误切断"来间接判断编码器在工作
（转起来不再断续 = 有反馈了）。

## 4. 故障速查表

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 电源灯不亮 | 电池没电 / 开关 / 插头 / 螺丝夹线皮 | 逐项查，插充电器唤醒保护板 |
| 电源灯亮，电机不动，板子不热 | STBY 没高 / AIN2 悬空（刹车）/ 信号线没到 | 先接 STBY 到 E13；确认 AIN2 接 GND |
| **板子烫手** | **STBY 倒灌 3V3（规则一）** / 电机堵转过流 | **立刻断电**，STBY 悬空 |
| 转半秒就停，反复抽 | 堵转保护误判（没编码器）| 正常现象，接编码器或接受断续 |
| 电机只嗡嗡响不转 | 电压太低（<2V）/ 机械卡住 | 加占空比；手动转一下确认不卡 |
| FPGA 突然重启 | 5V 轨被拉垮（短路 / 电机直接吃 USB 5V）| 检查有没有短路，别用 FPGA 的 5V 带电机 |

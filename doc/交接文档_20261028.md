## 2. 怎么跑起来（三条命令）

### 2.1 仿真（不需要硬件）

```powershell
cd D:\dsh-ws\robot_project
powershell -ExecutionPolicy Bypass -File sim\toolchain\run_tb.ps1
# 或只跑一个：  ... run_tb.ps1 tb_motion_decision
```

> ⚠️ **ModelSim 在中文用户名下会崩**（`filename is invalid on this platform`），
> 必须在跑之前设：`$env:TEMP='D:\dsh-ws\_tmp'; $env:TMP='D:\dsh-ws\_tmp'`

### 2.2 静态检查

```powershell
powershell -ExecutionPolicy Bypass -File tools\run_checks.ps1
```

检查项：编码 / lint / 例化 / 位宽溢出 / 声明顺序 / 4 个模型自测。

### 2.3 综合

```powershell

cd D:\dsh-ws\robot_project\tools\fpga_build
D:\Gowin\Gowin_V1.9.12_x64\Gowin_V1.9.12_x64\IDE\bin\gw_sh.exe build_all.tcl
# 成功标志：输出 RESULT_OK，产物 build\robot\impl\pnr\robot.fs
```

### 2.4 烧写

**A. 烧 SRAM（断电即失效，日常调试用，7 秒）**

```powershell
$PRG = 'D:\Gowin\Gowin_V1.9.12_x64\Gowin_V1.9.12_x64\Programmer\bin\programmer_cli.exe'
& $PRG -d GW5AT-138C --fsFile '<fs路径>' --operation_index 2
```

**B. 烧 Flash（断电不丢，交付/比赛用，约 100 秒）—— 只能用 GUI**

```
programmer.exe
 ① 放大镜 Scan（扫不到就先给板子断电重启）
 ② 双击器件行
 ③ Access Mode : External Flash Mode Arora V
 ④ Operation   : exFlash Erase, Program, Verify Arora V   ← 前后都不能带修饰
 ⑤ File name   : build\robot\impl\pnr\robot.bin            ← 用 .bin，不是 .fs
 ⑥ Save → 点绿色 ▶
```

成功日志：`Try to program spi flash: 0xC22018!` → `Program and Verify Flash successfully.`

## 3. 接线（只抄这张表）

> 完整版见 [`doc/接线总表.md`](接线总表.md)；**这里只放最常用的**。

### 3.1 三条红线 ⚠️

```
① FPGA 的 5V/3V3    绝不接驱动板 Vin+
② 驱动板的 5V/3V3   绝不接回 FPGA（两个稳压器倒灌发烫）
③ 舵机电源绝不要从 FPGA 取（MG996R 堵转 1~2.5A）
```

### 3.2 电源

```
电池 XT60
 ├ 红 →[5A 保险丝]→[船型开关]→ 汇流板【+12V】(3P，三格焊通)
 │                                   ├─① 电池+
 │                                   ├─② 驱动板 Vin+（18AWG）
 │                                   └─③ UBEC 红 + DC-DC 红
 └ 黑 →──────────────────────── 汇流板【GND】(3P，三格焊通)
                                     ├─① 电池− + FPGA GND（细线）
                                     ├─② 驱动板 Vin−（18AWG）
                                     └─③ UBEC 黑 + DC-DC 黑

UBEC  OUT 6V → 舵机电源正极
DC-DC OUT 9V → FPGA 的 DC 5.5×2.1 圆口   ★ 先万用表量到 9.0V 再插
充电宝 Type-C → K230
```

### 3.3 信号（FPGA 侧）

| 用途 | 信号 | 球号 | 孔位 |
|---|---|---|---|
| **电机0 左前** | PWM / 方向 / 二方向 | `A13` / `A18` / `F19` | 底20 / 底18 / 底1 |
| **电机1 右前** | | `A14` / `A19` / `F18` | 顶20 / 顶18 / 底2 |
| **电机2 左后** | | `A15` / `F13` / `E19` | 底19 / 底17 / 底3 |
| **电机3 右后** | | `A16` / `F14` / `D20` | 顶19 / 顶17 / 底4 |
| 驱动板 STBY | `m_en` | `E13` | 底16（**建议先悬空**）|
| 编码器 0~3 | A/B | `E14`/`C13`、`B13`/`D14`、`D15`/`C14`、`C15`/`B15` | 顶16/底14、顶14/底13、顶13/底12、顶12/底11 |
| **K230 TX→FPGA** | `uart_rx` | `F16` | **底5** |
| **FPGA→K230 RX** | `uart_tx` | `C19` | **顶7** |
| 升降舵机 前/后 | `lift_pwm[0/1]` | `B16` / `D17` | 顶11 / 底10 |

| 谁的地 | 接到 |
|---|---|

## 4. 哪些验过、哪些没验（重要）

### ✅ 已经在真机上验过

| 项 | 证据 |
|---|---|
| FPGA 加载 / 时钟 / 复位 / LED | LED0 常亮 |
| **Flash 固化 + 独立启动** | 拔 JTAG、断电重上电，D0 仍常亮 |
| **电池→降压→FPGA 整机独立供电** | 2026-10-29 实测：3S 电池 10.92V → 洞洞板汇流 → LM2596 调到 9.2V → FPGA DC 口，**D0 常亮**；焊点带载不烫 |
| **FPGA→PCA9685→舵机（4 只）** | 2026-10-29 晚实测：SERVO_IF=1，I²C 通（D3=led[3]=pca_init_done 亮），**4 只 MG996R 同时抬腿成功**。详见 `doc/舵机链路测试指南.md` |
| **WiFi 遥控全链路** | 2026-10-30 凌晨实测：手机网页 → K230 热点(192.168.169.1:8080) → UART 0x05 帧 → FPGA rc_rx。**D2(rc_active) 常亮、D3(指令非零) 按键时闪烁** = 遥控生效 ✓（电机未接线，只验到指令层）|
| **FPGA→K230 串口** | `board_bringup.run(['listen','3'])` → 276 帧、BCC 0 错、噪声 0 |
| RTL 功能 | 23 TB / 886 检查 / 0 错误 |
| 综合时序 | `RESULT_OK` |

### ❌ 完全没上板验过（风险最高）

| 项 | 为什么重要 |
|---|---|
| **4 个电机转不转 / 方向对不对** | `MOTOR_TEST_MODE=1` 专门用来验这个，**还没跑** |
| **4 个舵机动作 / 行程对不对** | 0.5ms~2.5ms 是否真的对应放平~抬起 |
| **限位开关** | 没接就只能靠超时判到位 |
| **编码器计数** | 速度环的前提 |
| **超声波 / TOF** | 当前固件 `TOF_ENABLE=0`，距离是**桩值 2000mm** |
| **摄像头 / 视觉** | K230 侧代码在，但没接摄像头跑过 |
| **IMU 姿态** | `IMU_ENABLE=0`，roll/pitch/yaw 恒 0 |

## 5. 踩过的坑（照这个列表避雷）

### 5.1 工具链

| 坑 | 现象 | 解法 |
|---|---|---|
| Gowin 不认中文路径 | `alog error: failed to open log file` | 在**纯 ASCII 目录**下跑 `gw_sh` |
| 仿真 work 库路径 | ModelSim 报路径错 | 必须纯 ASCII |
| ModelSim + 中文用户名 | `filename is invalid on this platform` | 设 `TEMP`/`TMP` 到 ASCII 目录 |
| `.ps1` 文件编码 | 中文乱码 + 语法报错 | **必须存成 UTF-8 with BOM** |

### 5.2 烧写

| 坑 | 现象 | 解法 |
|---|---|---|
| CLI 写 Flash | `Spi flash not found` | **只能用 GUI**，且 Operation 不能带修饰 |
| `... Background ...` | 容易失败 | 用最普通的 `exFlash Erase,Program,Verify` |
| `... thru GAO-Bridge ...` | `No gao bridge files found` | 没厂商桥接文件，不能用 |
| 做过 SRAM Erase 后 Scan | `No Gowin devices found` | 给板子**断电重启**再扫 |
| `.fs` 当 Flash 文件 | 34.7MB，Flash 只有 16MB | 用 **`robot.bin`（4.33MB）** |
| `robot.fs` 里真正的内容 | 只有 4.33MB | `.fs` 是填充过的容器 |

### 5.3 ARM（K230）侧

| 坑 | 现象 | 解法 |
|---|---|---|
| **`uart.any()` 谎报** | 缓冲有 1320B，`any()` 返回 1 → 每拍只读 1 字节 → 缓冲溢出 → **0 帧 / 299B 噪声** | 直接 `uart.read()`，别问 `any()` |
| TELEMETRY 第 0 字节 | 显示 `UNKNOWN(64)` | `state = b0 & 7`、`flags = (b0 >> 3) & 0xF` |
| USB-CDC 不动 | 打开成功但收不到字节 | **必须拉 DTR/RTS** |
| 没装 CanMV IDE | 不知道怎么跑板端脚本 | 用 `tools/k230_repl.ps1` 直连 REPL |

### 5.4 硬件

| 坑 | 后果 | 解法 |
|---|---|---|
| `STBY` 接 3V3 | 两路稳压器并联**发烫并烧输出级** | 悬空，或由 `E13` 驱动 |
| 驱动板 `Vin−` 与 `Vout+` 看错 | 把地接稳压输出 = 短路 | 只接顶部 `Vin+`/`Vin−` |
| 电机 6 针接中间 4 针 | 电机永远不转 | M+/M− 只接**最上、最下**两针 |
| 9V 没调就插 FPGA | 烧 FPGA | **先量到 9.0V** |
| 超声波接 5V | ECHO 输出 5V 打死 3.3V IO | 一定用 **3.3V** 供电 |
| 螺丝端子夹不住细线 | 一拽就掉 | 线**折两折**再夹（或上锡 / 管型端子）|
| 面包板走 12V | 触点额定 1A，会熔化 | **绝对不行**，用螺丝端子/杠杆端子 |

### 5.5 结构（OpenSCAD）

| 坑 | 现象 | 解法 |
|---|---|---|
| 通风孔挖到定位柱柱脚 | 柱子悬空，STL 实体数从 2 变 3 | 已加 `MOD_POSTS` + `vent_hits_post()` 自动避让 |
| `use <f>` 不导入顶层变量 | 参数全是 0 | 必须用 `include` |
| 共面 | `not a valid 2-manifold` | 错开 0.1mm |
| 中文文件名 | OpenSCAD 不能 `-D PART=` | 用临时文件改 `PART` |

## 9. 固件参数开关（`rtl/top.v` 开头）

| 参数 | 当前值 | 含义 |
|---|---|---|
| `MOTOR_TEST_MODE` | **0** | 1 = 4 轮同步脉冲自测（绕开状态机）|
| `TOF_ENABLE` | **0** | 0 = 距离用桩值 `DIST_STUB_MM=2000` |
| `TOF_IF` | **1** | 0 = I²C VL53L0X，1 = HC-SR04 |
| `SERVO_IF` | **0** | 0 = 直接 PWM（2 根脚），1 = PCA9685 |
| `IMU_ENABLE` | **0** | 1 才解算姿态（和 PCA9685 抢 I²C）|

> ⚠️ `SERVO_IF=1` 的前提是 `TOF_IF=1` 且 `IMU_ENABLE=0`（I²C 只有一条）。

## 10. 给接手人的三句实话

1. **RTL 不是瓶颈** —— 仿真和综合都过了，卡的是**硬件装配和实测**。
2. **最该先做的是"验电机方向"** —— 30 分钟，能把最大的不确定性消掉，而且是唯一必须"轮子离地"做的。
3. **所有"参数/引脚"改动只改两处**：`constraints/pin_table.csv`（引脚）和 `rtl/top.v` 开头的参数区（功能开关），别的地方都是派生的。

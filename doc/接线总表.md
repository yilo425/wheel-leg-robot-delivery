## 1. ★ 电源域（最容易出事的地方）

**三个电源域，只有"地"是共的。**

```
域 A：FPGA  —— **DC 9~12V 输入**（板上自带的电源座）；台架调试时才用 USB 5V
域 B：驱动板 —— 电池 Vin+/Vin- （4.5~15V，本项目 12V 电池）
域 C：舵机   —— 独立 5V 电源（充电宝/降压模块），**绝不从 FPGA 取**
```

### 共地（必须，缺一根全线不正常）

| 从 | 到 |
|---|---|
| 驱动板 `GND` | FPGA **顶排第 6** 或 **顶排第 15**（丝印 GND）|
| 舵机的 5V 电源负极 | FPGA 的 GND（**参考地**，只需一根细线）|
| K230 的 `GND`（排针 9/14）| FPGA 的 GND |

> **不共地的典型症状**：电机一启动串口就乱码、编码器计数乱跳、FPGA 偶尔复位。
> 原因是电机大电流在地线上产生压降，把逻辑地"抬起来"了。

### ⚠️ 三条红线

1. **不要把 FPGA 的 5V 或 3V3 接到驱动板的电源输入**（`Vin+`）—— 电流不够，会把 FPGA 拉复位。
2. **不要把驱动板的 `5V` / `3V3` / `Vout+` 接回 FPGA** —— 那是它自己的稳压输出，两个稳压器并联会互相倒灌发热。
3. **舵机不要从 FPGA 的 5V 取电** —— 舵机堵转电流 1A+，会直接拉垮 FPGA。

## 2. FPGA ↔ K230（ARM）—— 3 根

串口 115200 8N1，3.3V 直连，**交叉接**。

| K230（40 针排针）| → | FPGA | FPFA 孔位 |
|---|---|---|---|
| 排针 **11**（UART2_TXD）| → | **`F16`**（`uart_rx`）| **底排第 5** |
| 排针 **13**（UART2_RXD）| ← | **`C19`**（`uart_tx`）| **顶排第 7** |
| 排针 **9** 或 **14**（GND）| ↔ | **`GND`** | 顶排第 6 / 15 |

> **K230 侧代码用的是 GPIO 号，不是排针号**：
> `set_function(5, FPIOA.UART2_TXD)` = 排针 11；
> `set_function(6, FPIOA.UART2_RXD)` = 排针 13。

**协议**：帧 `AA 55 | VER | TYPE | LEN(2B) | DATA | BCC | 55 AA`，
BCC = XOR(VER,TYPE,LEN_H,LEN_L,DATA)。
ARM→FPGA 用 `0x02 VISION_RESULT` / `0x04 CONFIG`；FPGA→ARM 用 `0x10 TELEMETRY`（10Hz，13 字节）。

## 3. FPGA ↔ 驱动板（TB6612）

### 3.1 每个电机要 **3 根**（PWM + 方向 + 第二方向）

TB6612 每个通道有 `AIN1`/`AIN2` 两个方向输入，**互补才能正反转**：

| AIN1 (`m_dir`) | AIN2 (`m_dir2`) | 结果 |
|---|---|---|
| 1 | 0 | 正转 |
| 0 | 1 | 反转 |
| 0 | 0 | 滑行（**不转**）|
| 1 | 1 | 刹车（**不转**）|

### 3.2 完整对应表（4 个电机）

| 电机 | 信号 | FPGA 球号 | **孔位** | 驱动板引脚（2 路板）| 4 路板推测 |
|---|---|---|---|---|---|
| **0 左前** | PWM | `A13` | **底排 20** | `PWMA` | `PWMA` |
| | 方向 | `A18` | **底排 18** | `AIN1` | `AIN1` |
| | 第二方向 | `F19` | **底排 1** | `AIN2` | `AIN2` |
| **1 右前** | PWM | `A14` | **顶排 20** | `PWMB` | `PWMB` |
| | 方向 | `A19` | **顶排 18** | `BIN1` | `BIN1` |
| | 第二方向 | `F18` | **底排 2** | `BIN2` | `BIN2` |
| **2 左后** | PWM | `A15` | **底排 19** | — | `PWMC` |
| | 方向 | `F13` | **底排 17** | — | `CIN1` |
| | 第二方向 | `E19` | **底排 3** | — | `CIN2` |
| **3 右后** | PWM | `A16` | **顶排 19** | — | `PWMD` |
| | 方向 | `F14` | **顶排 17** | — | `DIN1` |
| | 第二方向 | `D20` | **底排 4** | — | `DIN2` |

> 轮子编号约定（**全项目统一**）：`0=左前 1=右前 2=左后 3=右后`，
> 必须和 `rtl/app/motion_decision.v` 的 `STEER_COEF` 一致，否则转向整个反过来。

### 3.3 驱动板使能脚 `STBY`（重要）

| 情况 | 接法 |
|---|---|
| **推荐** | **悬空**——多数 TB6612 模块的 `STBY` 内部上拉到它自己的 3V3 |
| 如果悬空电机不动 | 接 FPGA 的 **`E13`**（`m_en`，底排第 16）|

> ⚠️ **为什么不能随便接 3V3**：这块板的 `STBY` 和它的 `3V3` 是连通的。
> 从 FPGA 给它送高电平 = **把 FPGA 的 3.3V 和板子的 3.3V 并联** → 两个稳压器
> 互相倒灌 → **板子发烫**（2026-10-18 实测烫到手痛，并烧掉了输出级）。
> 要么悬空（板子自己拉高），要么由 `E13` 驱动。

### 3.4 只用一路的"最简测试接法"（3 根线）

```
驱动板 GND  ── FPGA 顶排第 6（GND）
驱动板 PWMA ── FPGA 底排第 20（A13）
驱动板 AIN1 ── FPGA 底排第 18（A18）
驱动板 AIN2 ── 驱动板 GND（板上短接，只能前进）
驱动板 STBY ── 悬空
```

## 4. 驱动板 ↔ 电机（MG310 六线）

MG310P20 是**带霍尔编码器的有刷减速电机**，6 根线：

| 线 | 作用 | 粗细 |
|---|---|---|
| **红** | 电机 **M+** | 最粗 |
| **黑** | 电机 **M−** | 最粗 |
| **VCC** | 编码器电源（3.3~5V）| 细 |
| **GND** | 编码器地 | 细 |
| **A** | 编码器 A 相 | 细 |
| **B** | 编码器 B 相 | 细 |

> **电机的两根线不分正负**（接反只是反转）。判断方法：**最粗的两根 = 电机**，
> 或者看颜色（红/黑）；再或者看 6 针插头**最两端的两个孔**。

### 4.1 接到驱动板的电机接口（6 针）

驱动板（2 路板）的 `Motor_A` / `Motor_B` 两组 6 针，丝印顺序是：

```
Motor_A 组（从上到下）:        Motor_B 组:
  AO2   ← 电机 M+               BO1   ← 电机 M+
  3V3   ← 编码器 VCC            3V3   ← 编码器 VCC
  E1A   ← 编码器 A              E2A   ← 编码器 A
  E1B   ← 编码器 B              E2B   ← 编码器 B
  GND   ← 编码器 GND            GND   ← 编码器 GND
  AO1   ← 电机 M−               BO2   ← 电机 M−
```

**MG310 的 6 针插头是防呆的，直接插上即可**（插头和这个顺序是配套的）。

> ⚠️ 如果不用 6 针插座、而是自己接线：**M+ / M− 只接最上、最下两个针**，
> 中间的 4 个是编码器的（3V3/GND/A/B）。接到中间 = 电机永远不转。

## 5. FPGA ↔ 编码器

**如果编码器已经通过驱动板的 6 针接口**（推荐），那编码器信号从驱动板的
`Output_IO` 排针出来，再接 FPGA：

| 驱动板 | FPGA 球号 | **孔位** | 含义 |
|---|---|---|---|
| `E1A` | `E14`（`enc_a[0]`）| **顶排 16** | 左前 A 相 |
| `E1B` | `C13`（`enc_b[0]`）| **底排 14** | 左前 B 相 |
| `E2A` | `B13`（`enc_a[1]`）| **顶排 14** | 右前 A 相 |
| `E2B` | `D14`（`enc_b[1]`）| **底排 13** | 右前 B 相 |
| `E3A` | `D15`（`enc_a[2]`）| **顶排 13** | 左后 A 相 |
| `E3B` | `C14`（`enc_b[2]`）| **底排 12** | 左后 B 相 |
| `E4A` | `C15`（`enc_a[3]`）| **顶排 12** | 右后 A 相 |
| `E4B` | `B15`（`enc_b[3]`）| **底排 11** | 右后 B 相 |

> 编码器引脚在 FPGA 侧**配了内部上拉**（`PULL_MODE=UP`），
> 因为 MG310 的霍尔输出是**开漏**的。悬空时读到稳定高电平 → 计数为 0，不会乱跳。
>
> 编码器的**电源**由驱动板的 3V3（电机接口第 2 针）提供，不要额外接。

## 6. 驱动板 ↔ 电池

| 驱动板 | 接 |
|---|---|
| **`Vin+`**（顶部，靠右那个大焊盘）| 电池 **正极** |
| **`Vin−`**（顶部，`Vin+` 左边）| 电池 **负极** |

> ⚠️⚠️ **`Vin−` 和 `Vout+` 是两个完全不同的焊盘**：
> `Vin−` 在**顶部**（电源输入），`Vout+` 在**底部**（稳压器输出）。
> 往 `Vout+` 上接地 = **短路稳压器输出** → 会把共用 USB 5V 的 FPGA 拉复位，
> 还可能永久损坏板子的稳压器（2026-10-18 真实踩到）。
>
> 这块模块**没有反接保护**，`Vin` 接反 = 立刻报废。

### 电压

| 电池 | 能不能直接接 | 说明 |
|---|---|---|
| 7.4V（2S）| ⚠️ 不行 | MG310 额定 7.4V ✓，但 **FPGA 要 9~12V**，7.4V 带不动（要加升压）|
| **12V（3S）** | ✅ **推荐（全系统统一）** | TB6612 允许 4.5~15V；电机靠 `V_LIMIT_DUTY` 限到 ~53% |
| 5V | ✅ 能转但弱 | 适合空载测试 |

**限压靠 PWM 占空比**：固件参数 `V_LIMIT_DUTY = 68`（68/128 = 53%），
12V×0.53 = **6.4V** ✓（满电 13.8V 时 7.3V，仍在额定内）。

> 更好的做法：加一个 **12V→7.4V DC-DC 降压模块**（¥10），电机就不吃 12V 方波了。

## 7. FPGA ↔ 升降腿舵机（MG996R ×2）

### 7.1 舵机接线（每只 3 根）

| 舵机线 | 颜色（常见）| 接 |
|---|---|---|
| **信号** | 黄 / 橙 | FPGA 的 PWM 脚（见下表）|
| **电源 +** | **红** | **独立 5V 电源正极** ⚠️ 不要用 FPGA 的 5V |
| **地** | 棕 / 黑 | 独立 5V 电源负极 **+ FPGA 的 GND**（共参考）|

| 腿 | 信号脚 | FPGA 球号 | **孔位** |
|---|---|---|---|
| 前腿组 | `lift_pwm[0]` | `B16` | **顶排 11** |
| 后腿组 | `lift_pwm[1]` | `D17` | **底排 10** |

**PWM 规格**：50Hz，脉宽 **0.5ms（放下）~ 2.5ms（抬起）**，
中间值由 `CONFIG 帧 0x10`（0~100）连续调节，100 = 2.5ms = 与旧行为一致。

> 舵机供电必须独立：MG996R 堵转电流可到 **1A~2.5A**，
> 从 FPGA 的 USB 5V 取电会直接拉垮 FPGA（实测会重启）。

### 7.2 限位开关（每腿 1 个，可选但强烈建议）

| 腿 | 信号脚 | FPGA 球号 | **孔位** |
|---|---|---|---|
| 前腿 | `lift_lim_n[0]` | `C17` | **顶排 10** |
| 后腿 | `lift_lim_n[1]` | `B17` | **底排 8** |

接法：**开关一端接 FPGA 的 GND，另一端接信号脚**。
FPGA 内部有上拉 → **未按下读 1，按下（到位）读 0**（低有效）。

> 不接限位开关也能动：`main_fsm` 会退化成"超时判到位"
> （超时值可用 `CONFIG 帧 0x11` 调），但**不如限位可靠**。

### 7.3 舵机故障反馈（可选，一般不接）

| 腿 | 信号脚 | FPGA 球号 | **孔位** |
|---|---|---|---|
| 前腿 | `lift_fault_n[0]` | `B18` | **顶排 8** |
| 后腿 | `lift_fault_n[1]` | `C18` | **底排 7** |

低有效，**不接 = 内部上拉 = 1 = 正常** ✓ 所以不接完全没问题。

## 8. FPGA ↔ HC-SR04 超声波（4 根）

| 模块丝印 | 接 | FPGA 球号 | **孔位** |
|---|---|---|---|
| `Vcc` | **3V3** ⚠️ | — | **底排第 6** |
| `Gnd` | GND | — | 顶排第 6 |
| **`Trig`** | 输出 | `F20`（`sr04_trig`）| **顶排 1** |
| **`Echo`** | 输入 | `E18`（`sr04_echo`）| **顶排 2** |

> ⚠️ **强烈建议按 3.3V 供电**。模块按 5V 供电时 **ECHO 会输出 5V**，
> 而 FPGA 的 IO 是 3.3V —— **长期过压会慢慢打死 IO**（几天后才失效，极难查）。
> 欠压最多是模块不工作，不会烧任何东西。
>
> 如果 3.3V 下测不出来、必须用 5V：在 **ECHO 上串 1k + 2k 分压**（5V → 3.33V）。

**固件开关**：`TOF_IF = 1` 用超声波；`TOF_IF = 0` 用 I2C 的 VL53L0X（走 `C20`/`D19`）。

## 9. FPGA ↔ 上位机（可选的两条路）

### 9.1 调试串口（只发，接 USB-TTL）

| 信号 | FPGA 球号 | 说明 |
|---|---|---|
| `uart_tx_dbg` | `M15` | 输出，和发给 ARM 的**同一份** telemetry |

接法：**USB-TTL 的 RX ← M15**，**USB-TTL 的 GND → FPGA GND**，
电脑上用 `tools/uart_link_tool.py monitor COMx` 看。

> ⚠️ 实测 **M15 没有接到板载 USB 转串口芯片**（波特率 115200 下 0 字节），
> 所以插板子的 USB 口看不到串口，必须外接 USB-TTL。

### 9.2 板载 UART 焊盘（原来的串口位置）

板上右上角标着 `UART / TXD / RXD` 的两个小焊盘 = `M15` / `J21`。
**是焊盘不是排针**，插不了杜邦线，本项目已把串口挪到 `C19`/`F16`。

## 10. 板载器件（不用接线，仅供理解）

| 器件 | 引脚 | 说明 |
|---|---|---|
| 50MHz 晶振 | `Y18` | 板上固定 |
| LED0~LED3 | `M22` `N22` `L21` `K21` | 见下面的灯语 |
| LED4~LED8 | `K22` `J22` `H22` `M21` `N19` | 复用成状态/速度显示 |
| 按键 S0 | `F15` | 启动/停止（**开关式**：按一次进，再按一次出）|
| 按键 S1 | `A20` | 急停（低有效）|
| 按键 S4 | `B21` | **复位键**（按住会复位）|

> ⚠️ `N19` 同时被标为 LED8 和蜂鸣器 BEEP —— 上板需确认是否冲突（未验证）。

### 灯语（没有串口时的唯一观测手段）

| 灯 | 含义 |
|---|---|
| **D0** | 复位释放（上电常亮 = 板子活着）|
| **D1** | 电机使能中 |
| **D2** | 正在避障 / 越障 |
| **D3** | 故障（急停超时 / 堵转）|
| **D4/D5/D6** | `state_dbg` 二进制：0=IDLE `000`、2=AUTO `010`、3=AVOID `011`、4=LIFT `100`、5=GOAL `101`、6=ESTOP `110` |
| **D7** | `speed_scale[0]`（1=全速，0=慢/停）|

> ⚠️ **`D5` 亮在 state=2 和 state=6 时都成立**（它只是 bit1）。
> 判断 AUTO 要看"**D5 亮 + D6 灭 + D4 灭**"。

## 12. 接线顺序（照这个来，别跳）

```
① 断电！所有部件先不通电
② 先接【地】：FPGA GND ↔ 驱动板 GND ↔ 电池负极 ↔ 舵机电源负极
③ 再接【信号】：PWM / 方向 / 编码器 / 舵机 / 超声波 / 串口
④ 最后接【电源】：驱动板 Vin+ / Vin-（先确认极性！）
⑤ 上电顺序：FPGA USB → 舵机 5V → 驱动板电池
⑥ 断电顺序反过来：电池 → 舵机 5V → FPGA USB
```

## 13. 上电前检查（每条都是真实踩过的坑）

| 检查 | 为什么 |
|---|---|
| `Vin+` / `Vin−` 极性 | 模块**没有反接保护**，接反 = 报废 |
| 不是接在 `Vout+` 上 | 那是稳压器**输出**，接地会短路（实测把 FPGA 拉复位）|
| 有没有把 FPGA 的 3V3/5V 接到驱动板 | 两个稳压器并联会倒灌发烫 |
| `STBY` 是否悬空（不是接 3V3）| 从外部送高 = 倒灌（见 §3.3）|
| 地线是否真的共了 | 不共地：串口乱码 / 编码器乱跳 |
| **轮子是否离地** | 第一上电就会转 |
| 电池是否还有电 | 堵转几次就可能把保护板跳闸（插一下充电器可唤醒）|

## A.1 ★ 三条 3V3 红线（违反会打死 FPGA）

| # | 模块 | 必须接 | 为什么 |
|---|---|---|---|
| 1 | **限位开关模块**（3 针 VCC/GND/OUT）| **3V3** | 模块 VCC=5V 时 OUT 也是 5V → 灌进 FPGA 的 3.3V IO ✗ |

## A.2 4 通道电机驱动板（RZ7899 类，已到货）

### 排针定义

```
【左排针】从上到下          【右排针】从上到下

  BIN2  AIN2                  DIN2  CIN2
  BIN1  AIN1                  DIN1  CIN1
  E2A   E1A                   E4A   E3A

【底部】 4 个白色电机座（⚠️ 每一路的针序不一样，插前对丝印）
```

### 电源

## A.4 舵机 / 电机紧固（重要，**丢掉原厂螺丝**）

### ★ 统一规格：**M3 × 12**（舵机和电机都用它，买 24 颗）

| 位置 | 螺丝 | 吃进长度 | 核算 |
|---|---|---|---|
| **舵机中心**（每腿 1 颗）| **M3×12** | 花键 **4.9mm** | 腿 9 − 沉孔 4 = 5，+ 盘 2.1 → 12 − 7.1 = 4.9 ✓ |
| **电机 4 孔**（每腿 4 颗）| **M3×12** | 电机 **8mm** | 腿 6 − 沉槽 2 = 4 → 12 − 4 = 8 ✓ |

**配套**：

| 件 | 数量 | 用途 |
|---|---|---|
| **φ8 平垫**（厚 1~1.5）| 8 个 | 舵机沉孔里，防压坏 PETG |
| M3 普通平垫 | 10 个 | 螺丝"太长"时垫在头下 |

### ⚠️ 装配前 5 秒测试（省一次拆装）

```
手拧 M3×12 进电机孔：
  能拧 ≥8mm、不顶死   -> 直接用  ✓
  拧到 5~6mm 就顶死   -> 螺丝头下垫 1~2 个 M3 平垫  ✓
```

> **记住这条**：**螺丝太长 = 加垫片**（头抬高 → 螺纹少进去）✓
> **螺丝太短 = 换长的**（垫片救不了）✗

### 舵机螺丝的压紧顺序

```
螺丝头 → φ8 垫片 → 腿（φ8 沉孔 深 4）→ 舵机盘（厚 2.1）→ 花键
              ↑ 一颗 M3 同时压紧"腿 + 盘" ✓
```

**为什么这样能卡住 + 不打滑**：

| 途径 | 余量 |
|---|---|
| 六芒星 6 面形状配合 | 间隙 0.15mm（松一点；松了就滴 502）|
| M3 压紧的摩擦 | **16 倍** ✓ |
| 垫片防蠕变 | 长期不松 ✓ |

**防松**：滴中强度螺纹胶（乐泰 243）✓

## A.6 完整上电顺序（照这个来）

```
① 全部断电，只插 FPGA 的 JTAG
② 上 12V → 看 FPGA 板上的电源灯（3V3/1V1 都要亮）
③ 万用表直流档量：
     · 驱动板 Vin+ 对 GND        ≈ 12V
     · 驱动板 5V 输出对 GND      ≈ 5V
     · 舵机 5V 降压输出对 GND    ≈ 5~6V
     · FPGA 的 3V3 排针对 GND    ≈ 3.3V
④ 四组电压都对 → 接信号线
⑤ 烧 bitstream → 看 LED 灯语（见 §10）
⑥ 先测舵机（不动轮子）→ 再测电机
```

**任何一步电压不对 → 停，别接信号线** ✗

# 升降腿结构与尺寸设计（3D 打印一体件）

> 2026-10-18。**前提数据来自 `doc/采购清单.md` §2.2/§2.4**：
> 整车 ≈1.5 kg、每腿分担 ≈0.4 kg、MG996R 13 kg·cm、舵机**不能长期承重**。
> 本文在这个基础上把"腿"的具体尺寸、结构、打印工艺定下来。

---

## 0. 先明确：这条腿**不是用来站立的**

这是**摆臂式举升腿（lever/paddle）**，不是"机器人的腿"：

```
默认状态（0.5ms）：腿【收起】，离地，不承担任何重量  ← 占 99% 时间
举升瞬间（~2.0ms）：腿【伸出】撑地，把车头/车尾顶起来
举升结束：再收回，重量回到 4 个轮子上
```

**所以舵机只在"举升那 1~3 秒"受力**，其余时间不受力 ——
这是 §2.4"舵机不能长期承重"的正解：**让腿在默认状态离地，而不是靠止挡硬顶**。

> ⚠️ 但**止挡仍然必须做**（见 §5）：万一腿被地面顶住，
> 力要走进结构而不是舵机齿箱。

---

## 1. 关键尺寸的推导

### 1.1 力矩与长度的关系

舵机需要克服的力矩：

```
T = F × d          F = 每条腿分担的重量（含动载）
                   d = **水平力臂** = 舵机轴到触地点的水平距离
                       = L × cosθ     L = 腿长，θ = 腿与水平面的夹角
```

**注意 `d` 是水平距离，不是腿长** —— 腿越接近竖直，力臂越小、越省力。

### 1.2 三种腿长的力矩对照

按 `F = 0.4 kg × 9.81 = 3.9 N`（静态）+ **2 倍动载** = 7.8 N，
取 θ=45°（水平力臂 `d = 0.71L`）：

| 腿长 L | 力臂 d | 所需扭矩（含 2× 动载）| 余量 v.s. **堵转 13** | 余量 v.s. **降额 6.5** |
|---|---|---|---|---|
| 60 mm | 42 mm | 3.4 kg·cm | 3.8 倍 ✓ | **1.9 倍** ✓ |
| **70 mm** | **49 mm** | **4.0 kg·cm** | **3.3 倍** ✓ | **1.6 倍** ✓ 推荐 |
| 80 mm | 57 mm | 4.5 kg·cm | 2.9 倍 ✓ | **1.4 倍** ⚠️ 偏紧 |
| 100 mm | 71 mm | 5.7 kg·cm | 2.3 倍 ⚠️ | 1.1 倍 ✗ |
| 120 mm | 85 mm | 6.8 kg·cm | 1.9 倍 ⚠️ | 1.0 倍 ✗ |

> **两个余量为什么差一倍**：MG996R 标称 **13 kg·cm 是堵转扭矩**。
> 连续负载要按 **50% 降额（6.5 kg·cm）** 算才安全。
>
> 本项目的举升是**间歇动作**（每次 1~3 秒，然后休息），所以
> "v.s. 堵转"那一列更贴近实际；但**装车验收时按降额那列看**更保险。
>
> **结论：L = 70 mm** 是两列都留有余量的唯一选择（1.6 倍降额余量）。
> 如果台阶特别高必须用 80mm，就**必须保证触地角 θ≥45°**。

**最坏情况（腿水平，θ=0，力臂 = L 全长）**：

| L | 扭矩（含 2× 动载）| v.s. 降额 6.5 |
|---|---|---|
| 70 mm | 5.6 kg·cm | **1.2 倍** ⚠️ |
| 80 mm | 6.4 kg·cm | 1.0 倍 ✗ 打平 |

> 所以**设计上必须避免"腿在水平位置吃力"**：
> 让腿从"斜上 45°"动起来，靠惯性**快速扫过水平区**，
> 真正的负载发生在 60° 以上（力臂 ≤0.5L，扭矩再降 30%）。

### 1.3 举升高度够不够

底盘上升量 `h = L(sinθ₂ − sinθ₁)`（θ 以水平为 0，向上为正）：

| L=70mm | θ₁（收起）| θ₂（举升）| 上升量 h |
|---|---|---|---|
| 方案 A | −45°（斜上后方）| +90°（竖直）| 70×(1+0.707) = **120 mm** |
| 方案 B | −45° | +135°（斜下前方）| 70×(0.707+0.707) = **99 mm** |

**两条方案的举升能力都远超需要的 30~50mm** ——
所以实际用 `CONFIG 帧 0x10`（抬腿高度 0~100）把行程**限制在够用的那一小段**，
既省力又不会把车顶翻。

> 推荐：**平时用 height = 45~55**（约 30~40mm 举升），
> 只有遇到意外高的台阶才临时加大。**不要一上来就用 100。**
>
> ⚠️ 反过来说：**L=70mm 的腿有 3 倍多的举升余量，说明"腿长"不是瓶颈，
> 扭矩才是**。所以宁可短一点、把舵机余量留足。

## 2. 推荐构型

### 2.1 布置（俯视）

```
        ┌─────────────────────────────┐
        │  ○ 前左腿         前右腿 ○   │   ← 前腿组（lift_pwm[0]）
        │  ◎ 前左轮         前右轮 ◎   │
        │                             │
        │         [电池/主板]          │   ← 重心尽量低、居中
        │                             │
        │  ◎ 后左轮         后右轮 ◎   │
        │  ○ 后左腿         后右腿 ○   │   ← 后腿组（lift_pwm[1]）
        └─────────────────────────────┘
           ◎ 轮    ○ 举升腿
```

| 项 | 建议 | 理由 |
|---|---|---|
| 腿的位置 | **四角，与轮子同一前后站位** | 举升点正好在轮子触地线上，不产生额外倾覆力矩 |
| 腿的横向位置 | **轮子内侧 5~10mm** | 不碰轮子，又能略微加宽支撑 |
| 摆动平面 | **车身纵向（前后摆）** | 举升方向与越障方向一致 |
| 舵机轴方向 | **横向（左右）** | 输出轴水平，腿在竖直平面内摆 |

### 2.2 摆角定义

```
        收起（默认）                 举升中                完全伸出
            ↑ 45°                                          
    ────────┼──────── 舵机轴（水平）  ────────┼────  ────────┼────
            │                                │  ╲            │  ╲
            ╱ 腿                             │   ╲ 腿        │   ╲
                                               ╲              │    ╲ 腿
                                                ╲             │     ╲
```

| 状态 | 脉冲（见 `servo_lift.v`）| 建议角度 | 说明 |
|---|---|---|---|
| 收起 | 0.5 ms | **−45°（斜上后方）** | 必须离地 ≥15mm，不能拖地 |
| 触地 | ~1.5 ms | **0°（水平）→ 立即越过** | **不要在这里停**，力臂最大 |
| 举升 | 2.0~2.2 ms | **60~90°** | 有效工作区，力臂 0.5L~0 |
| 极限 | 2.5 ms | 135° | 留作余量，平时不用 |

> **关键**：让腿从"斜上 45°"一路**扫过水平**、**不要停在水平**。
> 舵机的持续负载应发生在 60° 以上（力臂 < 0.5L）。

## 3. 单条腿的尺寸（推荐值）

以 **L = 70 mm（舵机轴 → 触地点）** 为基准：

| 部位 | 尺寸 | 说明 |
|---|---|---|
| **有效长度** | **70 mm** | 轴心到触地垫中心 |
| 根部宽度 | **20 mm** | 与舵机盘匹配，越宽抗扭越好 |
| 中部宽度 | 17 mm | |
| 端部宽度 | **13 mm** | 收窄减少刮碰 |
| 根部厚度（受力方向）| **8 mm** | 弯矩最大处 |
| 中部厚度 | 6 mm | |
| 端部厚度 | **4.5 mm** | |
| **触地垫** | φ14 × 3 mm，**边缘倒圆 R2** | 圆角避免"啃"地和打滑 |
| 根部轮毂 | φ22，**内嵌舵机盘** | 见 §4.2 |

**截面形状**：不要做纯矩形 —— 加一条 **2mm 高的中央加强筋**（工字/十字截面），
抗弯刚度提升 2~3 倍，重量只多 15%。

```
        端部                      根部
        ┌──┐                  ┌────┐
        │  │                  │    │   ← 20 宽
     ┌──┤  ├──┐            ┌──┤    ├──┐
     │  │██│  │            │  │████│  │  ← ██ = 2mm 加强筋（两面各一条）
     └──┴──┴──┘            └──┴────┴──┘
     4.5 厚                   8 厚
```

> 如果实测台阶 >50mm、必须把 L 加到 80mm：
> 只把**长度**改大，宽度/厚度按比例 ×1.14 即可（根部 23 宽 × 9 厚）。

## 4. 3D 打印工艺

### 4.1 材料与参数

| 项 | 建议 | 理由 |
|---|---|---|
| 材料 | **PETG**（首选）/ PLA+（次选）| PETG 韧性好、抗冲击、不易脆断；PLA 硬但脆 |
| 填充 | **60~80%**（根部区域 100%）| 这是承力件，别用 20% |
| 壁厚 | **4 圈（≥1.6mm）** | 外壁承担大部分弯曲应力 |
| 层高 | 0.16~0.2 mm | |
| 支撑 | 尽量**不需要**（设计成无悬空）| 见 §4.3 |

### 4.2 ★ 打印方向（决定成败）

**弯曲应力的方向 = 腿的长度方向**，而 3D 打印件的**层间结合力最弱**。

```
✗ 错误：立着打（腿竖直躺在热床上）
    层平面垂直 → 弯曲时层间受拉 → 从中间"劈开"

✓ 正确：平躺打（腿的长度沿 X-Y 平面，厚度方向沿 Z）
    层线沿长度方向 → 弯曲应力在层内 → 强度接近注塑件
```

**具体摆放**：让 70mm 那条边沿打印平台的 X 轴，厚度（8mm）沿 Z 轴。

### 4.3 ★ 金属销加强（强烈建议）

纯打印件的**根部**是层间剪切最危险的地方。加一根 **φ3 mm 钢轴/碳纤棒**
贯穿腿的脊背（从根部轮毂到中部，长 50mm），用环氧点固：

```
    根部轮毂
       │
   ════╪═══════════════════════  ← φ3 销（埋入打印时预留的 3.2mm 孔）
       │          腿身
```

**效果**：抗弯刚度提升 3~5 倍，且即使打印层裂了也不会断开。
成本 ≈ ¥1，强烈建议。

### 4.4 舵机盘连接（一体件的关键接口）

腿是"一体打印"，但舵机盘是**金属/塑料的标准件**，必须可靠传递扭矩：

| 做法 | 说明 |
|---|---|
| **A（推荐）** | 腿根部挖一个**与舵机盘同形的沉槽**（φ20×2.5mm），盘嵌入后用 **4× M2 自攻螺钉** + **1× M3 顶丝压在花键上** |
| B | 直接用**长螺钉穿过舵机盘中心孔**，螺母在腿另一侧压紧 |
| ✗ 不用 | 只靠打印件的摩擦力夹住 —— 举升时必打滑 |

> ⚠️ 舵机盘的花键是 **21 齿**（MG996R），槽要留 **0.2mm 间隙**，
> 太紧装不进、太松会旷。

## 5. ★ 机械止挡（**这条不做，舵机 10 分钟就烫**）

需求来自 `采购清单.md` §2.4。

### 5.1 止挡装在哪

**在"收起"极限位置装一个止挡**（不是举升位置）：

```
                        止挡面（车体上的凸台）
                          ↓
    ═══════════════════════╗
                           ║  ← 腿收起时贴住这里
                          ╱
                       ╱ 腿
```

**作用**：腿收起时如果被地面/障碍往上顶，力由**止挡面 → 车体**承受，
舵机齿轮不受力。

### 5.2 止挡的三条要求

| 要求 | 数值 |
|---|---|
| 接触面积 | ≥ 60 mm²（别做成线接触，会压溃）|
| 材料 | 同打印件即可，但**加厚 3mm** |
| 位置 | 让腿收起时**离地 15~20mm**（不拖地，但也不太远）|

### 5.3 为什么不做"举升位置的自锁"

理论上可以用蜗轮蜗杆/丝杆自锁，但那要**换执行器**（舵机做不到）。
本项目用"**默认离地**"来替代自锁：舵机不举升时根本不接触地面 ✓ 更简单可靠。

## 6. 稳定性设计

### 6.1 底盘三围（建议）

| 参数 | 建议值 | 为什么 |
|---|---|---|
| **轴距**（前后轮中心距）| **130~150 mm** | 越长越抗前后倾覆，但转弯半径变大 |
| **轮距**（左右轮中心距）| **110~130 mm** | 要 > 车宽才能抗侧倾 |
| **重心高度** | **< 45 mm**（越低越好）| 电池贴底板放 |
| 离地间隙 | 12~15 mm | 太小会托底 |

### 6.2 倾覆校核（越障时必须成立）

举升时，支撑多边形会变。以"前腿举升"为例：

```
   前腿触地点 ●              后轮触地点
              │←── 必须 ──→│
              │    重心在这里面   │
    ──────────┴───────●───────┴────────
                      ↑
                    重心（投影）
```

**规则**：**重心的地面投影必须始终落在"当前着地点构成的凸多边形"内**。

| 阶段 | 着地点 | 要求 |
|---|---|---|
| 正常行驶 | 4 轮 | 重心在 4 轮中间 |
| 前腿举升 | 2 后轮 + 2 前腿 | 重心在**后轮与前腿之间** |
| 前轮上台阶 | 2 后轮 + 2 前轮（在新高度）| 重心在轴距内 |
| 后腿举升 | 2 前轮 + 2 后腿 | 重心在**前轮与后腿之间** |

### 6.3 三条实用规则

1. **电池尽量低、尽量居中** —— 它是最重的单体（0.25kg）。
2. **腿的触地点不要超出轮子太多** —— 超出 20mm 以内为好；
   超太多会把"举升"变成"撬杠"，把车顶翻。
3. **左右两条腿必须完全对称** —— 同一组的两个舵机（前左/前右）如果角度不一致，
   车会侧倾，一侧轮子离地 → 打滑/翻车。

## 7. 装配与调试顺序

```
① 打印 4 条腿（同一份 STL，保证一致）→ 装金属销 → 装舵机盘
② 舵机固定到车体，**先不装腿**，用代码让舵机转到 0.5ms / 2.5ms，确认方向
③ 装腿（**先只装一条**），确认收起时离地 15~20mm
④ 四条装齐，用 CONFIG 0x10 = 100 慢慢试，找"刚好够上台阶"的高度
⑤ 调到能上目标台阶后，把这个高度记下来，写进 CONFIG 默认值
⑥ 连续举升 20 次，摸舵机温度（**应该只是温的，不烫手**）
```

> 第 ⑥ 步是**验收标准**：如果烫手，说明要么力臂太大（腿太长/角度不对），
> 要么止挡没起作用（重量落在舵机上）。

## 8. 还需要你确认的 4 个数

设计里我用了项目文档的假设值，**下面这些一旦实测不同，尺寸要跟着改**：

| 项 | 我用的假设 | 影响 |
|---|---|---|
| **整车重量** | 1.5 kg | 直接线性影响扭矩/腿长上限 |
| **目标台阶高度** | 30~40 mm | 决定需要多少举升行程（`CONFIG 0x10` 的目标值）|
| **轮子直径** | φ50~65 mm（采购清单）| 决定离地间隙、腿的安装高度 |
| **底盘长×宽** | 建议 160×130 mm | 决定轴距/轮距、腿的布置 |

**其中最关键的是"目标台阶高度"** —— 如果比赛要求跨 50mm 以上，
L=70mm 就不够了，要升到 90~100mm **并且**换 20kg·cm 的舵机（DS3218）。

# 舵机接线表（4 舵机 / 两两一组）

> 2026-10-25。对应 `rtl/top.v` 的 `SERVO_IF` 参数。
> 引脚位置以 `constraints/top.cst` 为唯一权威（跑 `python tools/audit_pins.py` 看孔位）。

---

## 0. 结论：用 PCA9685 → **不需要 Y 线** ✓

| 方案 | Y 线 | 说明 |
|---|---|---|
| **A. PCA9685（推荐）** | **不需要** ✓ | 4 个舵机各插一个通道；FPGA 给 ch0/ch1 写同一个值、ch2/ch3 写同一个值 → 逻辑上还是"两两一组" |
| B. FPGA 直驱 | **需要 2 根** ✗ | 1 个引脚带 2 个舵机，必须 Y 线分出来 |

**为什么推荐 A**：

1. 板子已经画进车身第一层（4 个穿孔柱 + 2mm 槽），不装就空着
2. 少 2 个接插件（Y 线是舵机系统里最容易松的环节）
3. 以后想单独调某个舵机的中位，改驱动器里一个计数就行，不用换线
4. FPGA 省 2 根引脚（B16/D17 空出来）

**前提**：`SERVO_IF = 1`（见 §5 的 RTL 状态）

---

## 1. 方案 A：PCA9685（无 Y 线）

### 1.1 板子 → FPGA（4 根）

| PCA9685 | 接哪里 | 孔位 | ⚠️ |
|---|---|---|---|
| `VCC` | **3V3** | 底排 6（UART 那边那个 3V3）| **绝不能接 5V**，否则 SDA/SCL 变 5V 打进 FPGA |
| `GND` | GND | 顶排 6 | |
| `SCL` | `i2c_scl` = **C20** | 顶排 4 | 板上自带 10k 上拉 |
| `SDA` | `i2c_sda` = **D19** | 顶排 3 | 同上 |

> `OE` 不接（内部下拉 = 使能输出）。
> 地址默认 `0x40`，对应 `SERVO_PCA_ADDR = 7'h40`。

### 1.2 舵机电源 → 板子（2 根粗线）

| PCA9685 | 接 |
|---|---|
| `V+`（螺丝端子）| UBEC / 12→5 降压的 **+6V 红线**（剥 5mm 拧紧）|
| `GND`（螺丝端子）| 降压的 **GND 黑线**，**再并一根细线到 FPGA GND** |

> ⚠️ `V+` **最大 6V**（丝印写着 `V+: 6V Max`）。降压调到 **5.5~6.0V** 再用，别给 12V。
> ⚠️ 图里写了：**螺丝端子有防反接，侧边排针没有**。所以电源一定走螺丝端子。

### 1.3 舵机插哪个通道（两两一组）

| 通道 | 舵机 | FPGA 内部 |
|---|---|---|
| **ch0** | 前左 | `lift_cmd[0]`（前腿组）|
| **ch1** | 前右 | `lift_cmd[0]`（同值）|
| **ch2** | 后左 | `lift_cmd[1]`（后腿组）|
| **ch3** | 后右 | `lift_cmd[1]`（同值）|
| ch4~ch15 | 空 | |

**接线顺序**（舵机 3P 头，**以板子丝印为准** —— 每块板的顺序不一样）：

| 舵机线 | 颜色 | 插到丝印 |
|---|---|---|
| 地 | 棕/黑 | `GND` |
| 电源 | **红** | `V+` |
| 信号 | 黄/橙/白 | `PWM` |

> **插反会烧舵机**：插之前拿万用表量一下排针上哪根是 +6V（对着 `V+` 那根），
> 再确认信号针在哪个位置（多数板是"信号靠板内、地靠板边"，但**不要凭经验，看丝印**）。

### 1.4 一页速查

```
FPGA C20 (顶4) ── SCL ──┐
FPGA D19 (顶3) ── SDA ──┤
FPGA 3V3 (底6) ── VCC ──┤ PCA9685
FPGA GND (顶6) ── GND ──┘
                          ├─ V+ ── 降压 +6V（螺丝端子）
                          ├─ GND ─ 降压 GND ── 细线并回 FPGA GND
                          └─ ch0..3 ── 4 个舵机（前左/前右/后左/后右）
```

## 2. 方案 B：FPGA 直驱（需要 2 根 Y 线）

### 2.1 信号（2 个引脚，各带 2 个舵机）

| 舵机组 | FPGA 引脚 | 孔位 | 中间加 | 带哪两个舵机 |
|---|---|---|---|---|
| 前腿组 | **B16** | 顶排 11 | **1 根 Y 线** | 前左 + 前右 |
| 后腿组 | **D17** | 底排 10 | **1 根 Y 线** | 后左 + 后右 |

**Y 线怎么用**：Y 线是"1 母 → 2 公"的 3P 分线。

```
FPGA B16 ──母头── Y 线 ──┬── 前左舵机（黄线 = 信号）
                          └── 前右舵机（黄线 = 信号）
        Y 线的另外两根（红/黑）也一分为二 → 两个舵机的电源并联
```

> ⚠️ **Y 线会把电源也并联**：2 个舵机同时从同一对红黑线取电 → 那对线的电流翻倍。
> 用 **20AWG 以上**的 Y 线，别用最细的那种杜邦线。

### 2.2 舵机电源（不经 Y 线时的接法）

如果 Y 线只分信号（把红/黑剪掉不用），电源要单独走：

| 舵机线 | 接 |
|---|---|
| 红（+6V）| 舵机分配板的 + 排 / 降压输出 |
| 黑（GND）| 舵机分配板的 − 排 / 降压 GND |
| 黄（信号）| Y 线 → FPGA B16 / D17 |

### 2.3 为什么还是建议别用 B

| | A. PCA9685 | B. 直驱 + Y 线 |
|---|---|---|
| Y 线 | 0 根 | **2 根**（¥6/根）|
| 接插件总数 | 4（舵机直插）| 4 舵机 + 2 Y 线 = **6 个** |
| 单舵机微调 | ✓ 改一个计数 | ✗ 只能整组动 |
| FPGA 引脚 | 2（I2C）| 2（PWM）|
| 依赖 | I2C 要通 | 无 |
| **现在的状态** | RTL 已写、单元测试 25/25 过；**顶层集成 TB 还没过** | ✓ 已验证可用 |

## 3. ⚠️ 4 条要命注意（两种方案都适用）

| # | 规矩 | 违反后果 |
|---|---|---|
| 1 | PCA9685 的 `VCC` 接 **3V3** | 接 5V → I2C 电平 5V → **打死 FPGA 引脚** |
| 2 | PCA9685 的 `V+` **≤6V** | 接 12V → 板子/舵机烧 |
| 3 | **共地**：舵机电源 GND 与 FPGA GND 必须通 | 不共地 → 舵机乱抖、FPGA 复位 |
| 4 | 舵机 3P 头**看丝印插**（GND/V+/PWM）| 插反 → 舵机烧 |

## 4. 上电检查顺序（照这个来，别跳）

```
① 全部断电，降压不接舵机
② 12V 上电，万用表量降压输出：调到 5.5~6.0V ✓ 断电
③ 接 PCA9685 的 V+/GND（螺丝端子）→ 上电 → 量 V+ 对 GND = 5.5~6.0V
④ 断电 → 接 I2C 4 根（VCC/GND/SCL/SDA）→ 上电
⑤ 量 PCA9685 的 VCC 对 GND = 3.3V ✓（不是 5V！）
⑥ 烧 bitstream（SERVO_IF=1），看舵机是否小幅动作（初始化会写中位）
⑦ 先试 1 个舵机（ch0），对了再插其余 3 个
```

**任何一步电压不对 → 停，别插舵机** ✗

## 5. RTL 状态与怎么切换

| 项 | 状态 |
|---|---|
| `pca9685_drv.v` | ✓ 写好，`tb_pca9685_drv` **25/25 通过** |
| `top.v` 里的 `SERVO_IF` 参数 + generate | ✓ 已加（`SERVO_IF=0` 默认）|
| `i2c_master` | ✓ 复用 TOF 那套 |
| **`sim/pca9685_slave_model.v`** | ✓ **新增**（0x40 从机：回 ACK、建模 MODE1/MODE2/PRE_SCALE/LEDn_OFF）|
| **`tb_top_servo_pca`（顶层集成）** | ✓ **26 项全过** |
| 完整回归 | ✓ **23 个 TB / 886 项 / 0 失败** |
| 综合 + 布局布线 | ✓ **RESULT_OK**，比特流已重出 |

**已修的真 bug**（这次才暴露）：舵机分支的 `i2c_master` 原来接在内部线 `pca_scl_i` 上，
再用 `assign i2c_scl = pca_scl_i;` 映射到引脚 —— 引脚上的**上拉回不到主机侧**，
主机会永远读到自己那根线是 `z`，卡在 START 直到超时。
现在改成和 TOF/IMU 分支一样：**`i2c_master` 直接接到 `i2c_scl` / `i2c_sda` 引脚**。

**切换方法**：

```verilog
// top.v 例化处
defparam u_top.SERVO_IF = 1;   // 或直接改参数默认值
// 同时必须：TOF_IF = 1 且 IMU_ENABLE = 0（否则 I2C 总线冲突）
```

> 现在两条路都验证过了：**直驱（SERVO_IF=0）和 PCA9685（SERVO_IF=1）**。
> 换的时候只要改 1 个参数 + 拔掉 2 根 Y 线，其它不动。

## 6. 和"两两一组"的关系（一句话）

> **硬件是否分组，和"用不用 Y 线"是两件事。**
> - 逻辑上永远是 2 组（前/后），RTL 里就是 `lift_cmd[1:0]` 两位。
> - 用 PCA9685：4 个通道、2 组同值 → **物理上不并联，但效果一样**。
> - 用直驱：1 个引脚带 2 个舵机 → **物理上并联，需要 Y 线**。
